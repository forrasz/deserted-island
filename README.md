# 無人島脱出

無人島から脱出する横スクロール2Dアクションゲーム(開発中)。
TypeScript + Vite + HTML5 Canvas で実装しています。

## 必要なもの

- Node.js 20 以上、npm

## 使い方

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバを起動 (http://localhost:5173)
npm test         # ゲームロジックのユニットテスト (Vitest)
npm run build    # 型チェックと本番ビルド (dist/)
```

## 操作

| 操作 | キー |
|---|---|
| 左へ移動 | `←` / `A` |
| 右へ移動 | `→` / `D` |
| ジャンプ | `Space` |

## ゲームの流れ

- ワールド中ほど(右へ進んだ先)に、ボス「カクレモモジリ」(緑の四角形)が左右に往復しています。
- ボスは **上から踏みつける**(落下しながら頭上に重なる)と体力が 1 減ります。体力は頭上のバーで確認でき、3 回踏むと倒せます。
- 側面から触れてもダメージはなく、押し戻されるだけです。被弾直後のボスは短い間ダメージを受けません。
- 倒すとイカダの部品(黄色の小さな四角形)が落ちます。触れると拾えて、画面左上の「イカダの部品: N」が増えます。

## 構成

- `src/core/`: 描画・DOM に依存しないゲームロジック(プレイヤー・ボス・部品・衝突判定。Vitest でテスト)
- `src/platform/`: Canvas 描画とキーボード入力
- `src/main.ts`: ゲームループの組み立て
- `openspec/`: OpenSpec による仕様・変更管理
