# 無人島脱出

無人島から脱出する横スクロール2Dアクションゲーム(開発中)。
TypeScript + Vite + HTML5 Canvas で実装しています。

## 必要なもの

- Node.js 20 以上、npm

## 使い方

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバを起動 (http://localhost:5173)
npm test         # ゲームロジックのユニットテスト (Vitest)
npm run build    # 型チェックと本番ビルド (dist/)
```

## 操作

| 操作 | キー |
|---|---|
| 左へ移動 | `←` / `A` |
| 右へ移動 | `→` / `D` |
| ジャンプ | `Space` |
| スタート / もう一度 | `Enter` |

## ゲームの流れ

1. **タイトル画面**で `Enter` を押すとスタートします。
2. 画面左上のHP(ハート 3 個)が、あなたの体力です。ステージには**ボス(カクレモモジリ)が 10 体**と、**ザコ敵が 30 体**います。
   - **ザコ敵**は、**上から踏みつける**(落下しながら頭上に重なる)と、1 回で倒せます。横などから触れるとHPが 1 減って少し跳ね上がり、約 2 秒間は無敵になります(点滅します。無敵の間は敵を通り抜けられます)。ザコ敵は何も落としません。
   - **ボス**は、**上から踏みつける**と体力が 1 減ります(体力は 3〜5 で、先のボスほど多く、速くなります)。倒すと**イカダの部品**を 1 個落とします。ボスに横から触れるとHPが 1 減って跳ね上がり、押し戻されます。
   - **HP が 0 になるとゲームオーバー**です。`Enter` で、最初からやり直せます。
   - ステージには**足場**があります。茶色の**崖**は壁で、横からは通れず、上に乗れます。薄い緑の**浮島**は、下からジャンプして通り抜け、上に乗れます(横から触れても通り抜けます)。登ると画面が上へスクロールします。
   - 地面の途中にある**穴**に落ちるとHPが 1 減り、直前の安全な足場に戻されます。戻った直後の 0.4 秒は操作できず、約 2 秒間は無敵です。
3. 倒したボスの位置に、イカダの部品(黄色の小さな四角形)が落ちます。触れると拾えて、画面左上の「イカダの部品: N/10」が増えます。**10 個そろう**と「イカダ: 完成!」と表示されます。
4. ステージの右端には海があります。イカダが完成するまでは砂浜で止まり、「イカダがないと海へは出られない…」と案内が出ます。イカダの完成後に海へ進むと**脱出成功**です。
5. **クリア画面**・**ゲームオーバー画面**で `Enter` を押すと、すべて初期状態からもう一度遊べます(倒した敵・ボスも復活します)。

1 面は、歩くだけで約 90 秒、ボス戦などを含めて約 3 分が目安です(時間切れはありません)。

### ザコ敵(10 種類)

| 名前 | 行動 |
|---|---|
| のろのろ | ゆっくり往復する |
| ちょこまか | 速く往復する |
| ぴょんぴょん | 往復しながら、一定間隔でジャンプする |
| ねぼすけ | 普段は動かない。近づくと、プレイヤーへ突進して、しばらく休む |
| つきまとい | 近づくと追いかけてくる(自分の持ち場からは出ない) |
| ふわふわ | 空中を上下に揺れながら往復する |
| きゅうこうか | 空中を往復し、真下に来ると急降下して、また上がる |
| はねっこ | 往復しながら、常に弾み続ける |
| かくれんぼ | 見えたり、隠れたりする。隠れている間は触れても何も起きず、踏めない |
| とっしん | ゆっくり歩き、一定間隔で突進する |

(ザコ敵は全部で 20 種類を予定していて、残りの 10 種類は今後追加します。)

## 画像素材(見た目の差し替え)

`public/assets/` に決められた名前の PNG を置くと、プレイヤー・ボス・部品・イカダ・背景・地面・海を画像で表示します。
**ファイルがなくても、従来の図形で遊べます。** 1 つずつ置いても構いません。ファイル名・推奨サイズ・向き・透過などの条件は [`public/assets/README.md`](public/assets/README.md) を見てください。

- 画像は当たり判定の矩形の高さに合わせて表示され、当たり判定そのものは変わりません。
- プレイヤーとボスの画像は右向きで描いてください(左へ進むときに反転します)。
- 画像素材の権利(著作権・ライセンス)は、利用者が確認してください。

## 構成

- `src/core/`: 描画・DOM に依存しないゲームロジック(プレイヤー・ボス・ザコ敵・部品・地形・ステージ・衝突判定・イカダと脱出・画面遷移。Vitest でテスト)
- `src/platform/`: Canvas 描画とキーボード入力
- `src/main.ts`: ゲームループの組み立て
- `openspec/`: OpenSpec による仕様・変更管理
