# 無人島脱出

無人島から脱出する横スクロール2Dアクションゲーム(開発中)。
TypeScript + Vite + HTML5 Canvas で実装しています。

## 必要なもの

- Node.js 20 以上、npm

## 使い方

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバを起動 (http://localhost:5173)
npm test         # ゲームロジックのユニットテスト (Vitest)
npm run build    # 型チェックと本番ビルド (dist/)
```

## 操作

| 操作 | キー |
|---|---|
| 左へ移動 | `←` / `A` |
| 右へ移動 | `→` / `D` |
| ジャンプ | `Space` |
| スタート / もう一度 | `Enter` |

## ゲームの流れ

1. **タイトル画面**で `Enter` を押すとスタートします。
2. 画面左上のHP(ハート 3 個)が、あなたの体力です。ワールド中ほどにいるボス「カクレモモジリ」(緑の四角形)は左右に往復しています。
   - ボスは **上から踏みつける**(落下しながら頭上に重なる)と体力が 1 減り、3 回踏むと倒せます。被弾直後のボスは短い間ダメージを受けません。
   - ボスに**横から触れる**と、あなたのHPが 1 減って、少し跳ね上がります。被弾した直後の約 2 秒間は無敵で(点滅します)、その間は続けて被弾しません。無敵中でも、ボスを踏みつけることはできます。
   - **HP が 0 になるとゲームオーバー**です。`Enter` で、最初からやり直せます。
3. 倒すとイカダの部品(黄色の小さな四角形)が落ちます。触れると拾えて、画面左上の「イカダの部品: N」が増え、部品がそろうと「イカダ: 完成!」と表示されます。
4. ワールドの右端には海があります。イカダが完成するまでは砂浜で止まり、「イカダがないと海へは出られない…」と案内が出ます。イカダの完成後に海へ進むと**脱出成功**です。
5. **クリア画面**・**ゲームオーバー画面**で `Enter` を押すと、すべて初期状態からもう一度遊べます。

## 画像素材(見た目の差し替え)

`public/assets/` に決められた名前の PNG を置くと、プレイヤー・ボス・部品・イカダ・背景・地面・海を画像で表示します。
**ファイルがなくても、従来の図形で遊べます。** 1 つずつ置いても構いません。ファイル名・推奨サイズ・向き・透過などの条件は [`public/assets/README.md`](public/assets/README.md) を見てください。

- 画像は当たり判定の矩形の高さに合わせて表示され、当たり判定そのものは変わりません。
- プレイヤーとボスの画像は右向きで描いてください(左へ進むときに反転します)。
- 画像素材の権利(著作権・ライセンス)は、利用者が確認してください。

## 構成

- `src/core/`: 描画・DOM に依存しないゲームロジック(プレイヤー・ボス・部品・衝突判定・イカダと脱出・画面遷移。Vitest でテスト)
- `src/platform/`: Canvas 描画とキーボード入力
- `src/main.ts`: ゲームループの組み立て
- `openspec/`: OpenSpec による仕様・変更管理
