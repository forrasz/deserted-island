# 無人島脱出

無人島から脱出する横スクロール2Dアクションゲーム(開発中)。
TypeScript + Vite + HTML5 Canvas で実装しています。

## 必要なもの

- Node.js 20 以上、npm

## 使い方

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバを起動 (http://localhost:5173)
npm test         # ゲームロジックのユニットテスト (Vitest)
npm run build    # 型チェックと本番ビルド (dist/)
```

## 操作

| 操作 | キー |
|---|---|
| 左へ移動 | `←` / `A` |
| 右へ移動 | `→` / `D` |
| ジャンプ | `Space` |
| スタート / もう一度 | `Enter` |

### 隠しコマンド(無敵モード)

タイトル画面かプレイ中に、キーボードで **`↑ ↑ ↓ ↓ ← → ← → B A`** を順に押すと、無敵モードになります(スマホでは使えません)。

- 敵・ボス・ボスの弾・ボーナスステージの石に当たってもダメージを受けません。穴に落ちても、戻されるだけでHPは減りません。踏みつけやハートでの回復は、これまでどおりです。
- 画面に「無敵モード」と表示され、プレイヤーが金色になります。
- もう一度入力しても解除されません。ゲームオーバー・クリアのあとに最初からやり直すと、オフに戻ります(タイトル画面で入力してからスタートした場合は、そのプレイではオンのままです)。
- 最後の `A` は左移動のキーでもあるので、押すと少し左へ動きます。

### スマホ(タッチ操作)

スマホは**横向き**で遊びます(縦向きだと「横向きにしてください」と表示され、ゲームは止まります。横向きに戻すと続きから再開します)。

| 操作 | 画面上のボタン・タップ |
|---|---|
| 左へ / 右へ移動 | 左下の「◀」「▶」(押している間だけ動く) |
| ジャンプ | 右下の「ジャンプ」(◀▶を押したままジャンプもできます) |
| スタート / もう一度 | タイトル・ゲームオーバー・クリア画面で、画面のどこかをタップ |

ボタンは、指で操作する端末でだけ表示されます。PC では表示されず、従来どおりキーボードで遊べます。

## ボーナスステージ(秘密の通路)

ステージのちょうど真ん中(中間地点、高所の浮島の回廊の下の地面)に、**秘密の通路**があります。見た目は普通の地面ですが、そこに立つと地面が抜けて、地下のボーナスステージが始まります(穴に落ちるミスとは違い、HPは減りません)。

- 地下の広間では、床の穴から**ハート**と**石**が決まった順番で飛び出します。
  - **ハート**を取るとHPが 1 回復します(最大 5 まで)。
  - **石**に当たるとHPが 1 減り、約 1.5 秒のあいだ動けなくなります(その間も無敵が始まります)。HPが 0 になるとゲームオーバーです。
- **30 秒たつか、広間の右端の出口に着く**と、地上の通路の位置へ戻ります。ボーナスの間、地上の敵やボスは止まっています。
- ボーナスステージは **1 回のプレイで 1 回だけ**です。もう一度遊ぶには、ゲームオーバーやクリアのあとで最初からやり直してください。

## ゲームの流れ

1. **タイトル画面**で `Enter` を押すとスタートします。
2. 画面左上のHP(ハート 5 個)が、あなたの体力です。ステージには**ボス(カクレモモジリ)が 10 体**と、**ザコ敵が 30 体**います。
   - **ザコ敵**は、**上から踏みつける**(落下しながら頭上に重なる)と、1 回で倒せます。横などから触れるとHPが 1 減って少し跳ね上がり、約 2 秒間は無敵になります(点滅します。無敵の間は敵を通り抜けられます)。ザコ敵は何も落としません。
   - **ボス**は、**上から踏みつける**と体力が 1 減ります。倒すと**イカダの部品**を 1 個落とします。ボスに横から触れるとHPが 1 減って跳ね上がり、押し戻されます。ボスは体ごとに**動きと攻撃が違い**、攻撃の前には**点滅(予備動作)**があるので、見てからよけられます(下の表)。
   - ボスや敵が出す**弾**と**衝撃波**に当たってもHPが 1 減ります。壊すことはできません。衝撃波は、ジャンプでよけられます。
   - **HP が 0 になるとゲームオーバー**です。`Enter` で、最初からやり直せます。
   - ステージには**足場**があります。茶色の**崖**は壁で、横からは通れず、上に乗れます。薄い緑の**浮島**は、下からジャンプして通り抜け、上に乗れます(横から触れても通り抜けます)。登ると画面が上へスクロールします。
   - 地面の途中にある**穴**に落ちるとHPが 1 減り、直前の安全な足場に戻されます。戻った直後の 0.4 秒は操作できず、約 2 秒間は無敵です。
3. 倒したボスの位置に、イカダの部品(黄色の小さな四角形)が落ちます。触れると拾えて、画面左上の「イカダの部品: N/10」が増えます。**10 個そろう**と「イカダ: 完成!」と表示されます。
4. ステージの右端には海があります。イカダが完成するまでは砂浜で止まり、「イカダがないと海へは出られない…」と案内が出ます。イカダの完成後に海へ進むと**脱出成功**です。
5. **クリア画面**・**ゲームオーバー画面**で `Enter` を押すと、すべて初期状態からもう一度遊べます(倒した敵・ボスも復活します)。

1 面は、歩くだけで約 90 秒、ボス戦などを含めて約 3 分が目安です(時間切れはありません)。

### ボス(10 体)

| # | 名前 | 動きと攻撃 | 踏める時 |
|---|---|---|---|
| 1 | カクレモモジリ | 往復し、ときどき地面にもぐる | もぐっている間は踏めず、触れもしない |
| 2 | トビハネ | 大ジャンプで、プレイヤーの方へ跳んでくる | 通常 |
| 3 | オオグイ | 予備動作のあと、プレイヤーへ突進する | 休んでいる間 |
| 4 | タマフキ | プレイヤーへ向けて、直進する弾を撃つ | 通常 |
| 5 | ナミノリ | ジャンプして着地し、衝撃波を左右へ出す | 休んでいる間 |
| 6 | フタゴ | 左右へ、放物線の弾を 2 発投げる | 通常 |
| 7 | ウキウキ | 空中に浮かび、真上から急降下し、目を回す | 目を回している間だけ |
| 8 | コロリン | 丸まって転がる | 転がっている間は踏めず、止まって目を回すと踏める |
| 9 | ジシン | 地面を踏み鳴らし、速い衝撃波を連続で出す | 休んでいる間 |
| 10 | **ヌシ(最終ボス)** | 大型(通常の約 2.5 倍)。突進・3 発の弾(高さが違う)・ジャンプと衝撃波 | 休んでいる間 |

**ヌシ**は体力が 12 あり、体力が半分(6)以下になると**形態変化**します。変身中(約 1.5 秒)は、踏んでもダメージがなく、触れても被弾しません。変身後は、動きが速くなり、突進が 2 連続、弾が 5 発、衝撃波が連続する強化形態になります。

ヌシは大きすぎてジャンプでは上に届かないため、**休んでいる間は身をかがめて低くなり**、そのときだけ踏めます(休み以外は踏めません)。かがんだら、すかさずジャンプで踏みましょう。

### ザコ敵(10 種類)

| 名前 | 行動 |
|---|---|
| のろのろ | ゆっくり往復する |
| ちょこまか | 速く往復する |
| ぴょんぴょん | 往復しながら、一定間隔でジャンプする |
| ねぼすけ | 普段は動かない。近づくと、プレイヤーへ突進して、しばらく休む |
| つきまとい | 近づくと追いかけてくる(自分の持ち場からは出ない) |
| ふわふわ | 空中を上下に揺れながら往復する |
| きゅうこうか | 空中を往復し、真下に来ると急降下して、また上がる |
| はねっこ | 往復しながら、常に弾み続ける |
| かくれんぼ | 見えたり、隠れたりする。隠れている間は触れても何も起きず、踏めない |
| とっしん | ゆっくり歩き、一定間隔で突進する |

(ザコ敵は全部で 20 種類を予定していて、残りの 10 種類は今後追加します。)

## 画像素材(見た目の差し替え)

`public/assets/` に決められた名前の PNG を置くと、プレイヤー・ボス・部品・イカダ・背景・地面・海を画像で表示します。
**ファイルがなくても、従来の図形で遊べます。** 1 つずつ置いても構いません。ファイル名・推奨サイズ・向き・透過などの条件は [`public/assets/README.md`](public/assets/README.md) を見てください。

- 画像は当たり判定の矩形の高さに合わせて表示され、当たり判定そのものは変わりません。
- プレイヤーとボスの画像は右向きで描いてください(左へ進むときに反転します)。
- 画像素材の権利(著作権・ライセンス)は、利用者が確認してください。

## 構成

- `src/core/`: 描画・DOM に依存しないゲームロジック(プレイヤー・ボス・ザコ敵・部品・地形・ステージ・衝突判定・イカダと脱出・画面遷移。Vitest でテスト)
- `src/platform/`: Canvas 描画とキーボード入力
- `src/main.ts`: ゲームループの組み立て
- `openspec/`: OpenSpec による仕様・変更管理
