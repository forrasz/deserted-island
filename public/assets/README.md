# 画像素材の置き場所

このフォルダに PNG 画像を置くと、ゲームの見た目が差し替わります。
**置いていないファイルは、従来の図形(四角形や色)で表示されます。** 1 つずつ少しずつ置いても動きます。

## ファイル一覧

| ファイル名 | 用途 | 推奨サイズ(目安) | 条件 |
|---|---|---|---|
| `player.png` | プレイヤー(人間) | 200×280(縦横比 5:7) | 透過、右向き、足元が画像の下端 |
| `boss.png` | ボス(カクレモモジリ) | 400×500(縦横比 4:5) | 透過、右向き、足元が画像の下端 |
| `part.png` | イカダの部品 | 128×128 | 透過 |
| `raft.png` | 完成したイカダ | 640×192(縦横比 10:3) | 透過、横から見た図 |
| `background.png` | 背景(無人島の風景) | 高さ 540、幅は任意(例 1920) | 左右が継ぎ目なくつながる |
| `ground.png` | 砂浜の地面 | 256×80 | 左右が継ぎ目なくつながる、上端が地面の表面 |
| `sea.png` | 海 | 256×80 | 左右が継ぎ目なくつながる、上端が水面 |

## 表示のされ方

- キャラクターや部品の画像は、**当たり判定の矩形の高さに合わせて縦横比を保って拡大縮小**され、足元が地面に揃います。当たり判定そのものは画像の大きさでは変わりません。
- プレイヤーとボスは、進む方向に合わせて**左右反転**されます。そのため、画像は**右向き**で描いてください。
- 背景は、カメラの動きより遅くスクロールします(横に繰り返されます)。
- 地面と海は、ワールドに固定されて横に繰り返されます。継ぎ目が目立たないように作ってください。
- 画像が読み込めない場合(ファイルがない・壊れている・5 秒以内に読み込めない)は、その対象だけ図形に戻ります。

## 注意

- 形式は PNG のみです。ファイル名は上の表のとおりにしてください。
- 大きすぎる画像は読み込みが遅くなります。推奨サイズ程度に抑えてください。
- 画像素材の権利(著作権・ライセンス)は、利用者が確認してください。
