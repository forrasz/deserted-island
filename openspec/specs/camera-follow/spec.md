# camera-follow Specification

## Purpose

画面より広いワールドを横方向・縦方向にスクロールして見せるため、プレイヤーに追従するカメラを提供する。プレイヤーが常に画面内に収まり、ワールドの外側が映らないようにする。

## Requirements

### Requirement: プレイヤーへの追従
システムは、プレイヤーが画面の水平方向の中央に表示されるようにカメラを移動させなければならない(SHALL)。プレイヤーが移動すると、地面などの背景が逆方向にスクロールして見える。

#### Scenario: 右へ移動したときのスクロール
- **GIVEN** プレイヤーがワールドの中ほどにいる
- **WHEN** プレイヤーが右へ移動する
- **THEN** プレイヤーは画面の中央付近に留まり、地面の模様などワールド上のオブジェクトが画面上で左へ流れる

#### Scenario: 画面外の領域への到達
- **GIVEN** ワールドの幅が画面幅より広い
- **WHEN** プレイヤーがワールドの右側へ進み続ける
- **THEN** プレイヤーは常に画面内に表示される

### Requirement: ワールド範囲外を映さない
システムは、カメラの表示範囲がワールドの左端・右端を越えないよう制限しなければならない(SHALL)。

#### Scenario: 左端付近
- **GIVEN** プレイヤーがワールドの左端付近にいる
- **WHEN** カメラが更新される
- **THEN** カメラの左端はワールドの左端(x = 0)より左にならず、プレイヤーは画面中央より左に表示される

#### Scenario: 右端付近
- **GIVEN** プレイヤーがワールドの右端付近にいる
- **WHEN** カメラが更新される
- **THEN** カメラの右端はワールドの右端を超えず、プレイヤーは画面中央より右に表示される

### Requirement: ワールド座標から画面座標への変換
システムは、ワールド上のすべての描画対象を、カメラの位置に応じた画面座標に変換して描画しなければならない(SHALL)。

#### Scenario: カメラ位置による描画位置の変化
- **GIVEN** カメラの x 座標が 100 である
- **WHEN** ワールド座標 x = 150 のオブジェクトを描画する
- **THEN** そのオブジェクトは画面の x = 50 の位置に描画される

#### Scenario: ワールドが画面幅以下の場合
- **GIVEN** ワールドの幅が画面幅以下である
- **WHEN** カメラが更新される
- **THEN** カメラの x 座標は 0 に固定される

### Requirement: 縦方向の追従
システムは、プレイヤーが画面の垂直方向の中央に表示されるように、カメラを縦にも移動させなければならない(SHALL)。プレイヤーが上へ登ると画面が上へ、下へ降りると画面が下へスクロールして見える。

#### Scenario: 上へ登ったときのスクロール
- **GIVEN** プレイヤーがステージの中ほどの高さにいる
- **WHEN** プレイヤーが上方向へ移動する
- **THEN** プレイヤーは画面の垂直方向の中央付近に留まり、ワールド上のオブジェクトが画面上で下へ流れる

#### Scenario: 常に画面内に表示される
- **GIVEN** ステージの高さが画面の高さより高い
- **WHEN** プレイヤーがステージの上端から下端まで移動する
- **THEN** プレイヤーは常に画面内に表示される

### Requirement: 縦方向でワールド範囲外を映さない
システムは、カメラの表示範囲がワールドの上端・下端を越えないよう制限しなければならない(SHALL)。

#### Scenario: 下端付近
- **GIVEN** プレイヤーが地面の上に立っていて、ステージの下端付近にいる
- **WHEN** カメラが更新される
- **THEN** カメラの下端はワールドの下端を超えず、地面は画面の下側に表示される

#### Scenario: 上端付近
- **GIVEN** プレイヤーがステージの上端付近にいる
- **WHEN** カメラが更新される
- **THEN** カメラの上端はワールドの上端(y = 0)より上にならない

#### Scenario: ワールドが画面の高さ以下の場合
- **GIVEN** ワールドの高さが画面の高さ以下である
- **WHEN** カメラが更新される
- **THEN** カメラの y 座標は 0 に固定される

### Requirement: ワールド座標から画面座標への縦の変換
システムは、ワールド上のすべての描画対象を、カメラの縦の位置に応じた画面の y 座標に変換して描画しなければならない(SHALL)。

#### Scenario: カメラの縦位置による描画位置の変化
- **GIVEN** カメラの y 座標が 800 である
- **WHEN** ワールド座標 y = 1000 のオブジェクトを描画する
- **THEN** そのオブジェクトは画面の y = 200 の位置に描画される

#### Scenario: 地面の画面上の位置
- **GIVEN** プレイヤーが地面の上に立っていて、カメラが下端に達している
- **WHEN** 画面を描画する
- **THEN** 地面の上面は、画面の下から 80 の位置に描画され、従来の画面と同じ見え方になる
