# sprite-rendering Specification

## Purpose

読み込んだ画像素材を使って、プレイヤー・ボス・部品・イカダ・背景・地面・海をリアルな見た目で描画する。画像の大きさに関わらず当たり判定の矩形に合わせて表示し、進行方向に応じて向きを変える。

## Requirements

### Requirement: 当たり判定の矩形への合わせ方
システムは、キャラクターやオブジェクトの画像を、当たり判定の矩形の高さに合わせ、縦横比を保って拡大縮小し、矩形の水平方向の中央、下辺に揃えて描画しなければならない(SHALL)。当たり判定の矩形そのものは画像によって変化させない。

#### Scenario: 縦長の画像
- **GIVEN** 当たり判定の矩形が幅 40・高さ 56 で、画像が幅 100・高さ 200 である
- **WHEN** 描画位置を計算する
- **THEN** 画像は高さ 56・幅 28 で、矩形の水平中央に、下辺を矩形の下辺に揃えて描画される

#### Scenario: 横長の画像
- **GIVEN** 当たり判定の矩形が幅 80・高さ 100 で、画像が幅 400・高さ 200 である
- **WHEN** 描画位置を計算する
- **THEN** 画像は高さ 100・幅 200 で、矩形の水平中央に、下辺を矩形の下辺に揃えて描画され、矩形の左右にはみ出す

#### Scenario: 足元が地面に揃う
- **GIVEN** プレイヤーが地面の上に立っている
- **WHEN** プレイヤーの画像を描画する
- **THEN** 画像の下辺は地面の上辺に揃う

#### Scenario: 当たり判定は変わらない
- **GIVEN** 画像素材が読み込まれている
- **WHEN** プレイヤーがボスを踏みつける、または側面に接触する
- **THEN** 判定は画像の大きさではなく、従来の矩形で行われ、結果は素材がない場合と同じになる

### Requirement: 進行方向による左右反転
システムは、プレイヤーとボスの画像を、進行方向に合わせて左右反転して描画しなければならない(SHALL)。素材は右向きで描かれているものとする。移動していない間は、直前の向きを保つ。

#### Scenario: 右へ移動
- **GIVEN** プレイヤーが右へ移動している
- **WHEN** 向きを判定する
- **THEN** 向きは右で、画像は反転せずに描画される

#### Scenario: 左へ移動
- **GIVEN** プレイヤーが左へ移動している
- **WHEN** 向きを判定する
- **THEN** 向きは左で、画像は左右反転して描画される

#### Scenario: 停止中は向きを保つ
- **GIVEN** プレイヤーが左へ移動したあと停止している
- **WHEN** 向きを判定する
- **THEN** 向きは左のままである

#### Scenario: ボスの往復
- **GIVEN** ボスが往復している
- **WHEN** 右へ進んでいるときと左へ進んでいるときの向きを判定する
- **THEN** 右へ進んでいるときは右向き、左へ進んでいるときは左向きで描画される

### Requirement: 背景の視差スクロール
システムは、背景の画像を、カメラの移動量より小さい割合で逆方向にずらして描画し、画面幅を超える範囲は横に繰り返して途切れないようにしなければならない(SHALL)。

#### Scenario: カメラが動いたとき
- **GIVEN** 背景の画像が画面幅と同じ幅で、視差の割合が 0.2 である
- **WHEN** カメラの x が 100 の位置で背景の位置を計算する
- **THEN** 背景は x = -20 の位置を基準に描画される

#### Scenario: 画像の幅を超えて進む
- **GIVEN** 背景の画像の幅が 960 である
- **WHEN** カメラが大きく移動して基準位置が画像の幅を超える
- **THEN** 基準位置は画像の幅で折り返され、画面全体が途切れずに背景で覆われる

#### Scenario: 背景の素材がない
- **GIVEN** 背景の素材が読み込めていない
- **WHEN** 画面を描画する
- **THEN** 従来の空色で塗りつぶされる

### Requirement: 地面と海の繰り返し表示
システムは、地面と海の画像を、ワールド座標に沿って横に繰り返して表示しなければならない(SHALL)。カメラが移動しても、画像の継ぎ目の位置はワールドに対して動かない。

#### Scenario: ワールドに固定された繰り返し
- **GIVEN** 地面の画像の幅が 200 で、カメラの x が 50 である
- **WHEN** タイルの描画開始位置を計算する
- **THEN** ワールド座標 0 のタイルの左端は画面の x = -50 に来る

#### Scenario: 海と砂浜の境界
- **GIVEN** 地面と海の両方の素材が読み込まれている
- **WHEN** 画面を描画する
- **THEN** 海の開始位置の手前は地面の画像、開始位置から右は海の画像で描かれ、境界は海の開始位置と一致する

#### Scenario: 地面の素材がない
- **GIVEN** 地面の素材が読み込めていない
- **WHEN** 画面を描画する
- **THEN** 従来の色と目印の縦線で地面が描かれる

### Requirement: 部品・イカダ・ボスの素材の使用
システムは、ボス、イカダの部品、完成したイカダを、それぞれの素材が読み込めている場合は画像で、読み込めていない場合は従来の図形で描画しなければならない(SHALL)。体力バー、HUD、案内の文字は、素材の有無にかかわらず従来どおり描画する。

#### Scenario: ボスの画像と体力バー
- **GIVEN** ボスの素材が読み込まれている
- **WHEN** 画面を描画する
- **THEN** ボスは画像で描画され、頭上に体力バーも描画される

#### Scenario: 部品の素材
- **GIVEN** 部品の素材が読み込まれていて、部品が地面に落ちている
- **WHEN** 画面を描画する
- **THEN** 部品は画像で描画され、拾得すると従来どおり消える

#### Scenario: イカダの素材
- **GIVEN** イカダが完成していて、イカダの素材が読み込まれている
- **WHEN** 画面を描画する
- **THEN** 砂浜の端に、イカダの画像が描画される

#### Scenario: 撃破されたボス
- **GIVEN** ボスが撃破されている
- **WHEN** 画面を描画する
- **THEN** ボスの画像は描画されない
