# enemy-system Specification

## Purpose

ステージに配置されるザコ敵の共通の仕組みを提供する。ザコ敵は種類ごとに行動が異なるが、踏みつければ 1 回で倒せ、それ以外の接触ではプレイヤーが被弾するという共通のルールを持つ。

## Requirements

### Requirement: ザコ敵の定義と配置
システムは、ザコ敵を、種類(行動)・位置・往復範囲で定義し、ワールド上の決められた位置に配置して更新しなければならない(SHALL)。ザコ敵の当たり判定の大きさは幅 40・高さ 40、体力は 1 とする。

#### Scenario: 開始時の配置
- **GIVEN** ゲームが開始された
- **WHEN** 最初の状態が作られる
- **THEN** ステージの定義に従ってザコ敵が配置され、すべて生存していて、体力は 1 である

#### Scenario: 画面外の敵の更新
- **GIVEN** ザコ敵がカメラの表示範囲の外にいる
- **WHEN** 更新が実行される
- **THEN** その敵も、定義された行動に従って更新される

#### Scenario: 敵の種類ごとの定義
- **GIVEN** 敵の定義の一覧がある
- **WHEN** すべての種類を取得する
- **THEN** 種類の識別子はすべて異なり、それぞれに名前と行動の定義がある

### Requirement: 踏みつけで 1 回で倒す
システムは、プレイヤーが落下中(下向きの速度)に、更新前の下辺が敵の上辺付近にあった状態で上から重なったとき、そのザコ敵を倒し、プレイヤーを上方向へ跳ね返さなければならない(SHALL)。プレイヤーは被弾しない。

#### Scenario: 上から踏みつける
- **GIVEN** プレイヤーが空中で落下していて、下辺がザコ敵の上辺に重なる
- **WHEN** 更新が実行される
- **THEN** ザコ敵は倒され、プレイヤーは上向きに跳ね返り、HPは変化しない

#### Scenario: 上昇中の接触は踏みつけではない
- **GIVEN** プレイヤーが上向きの速度でザコ敵と重なっている
- **WHEN** 更新が実行される
- **THEN** ザコ敵は倒されない

#### Scenario: 被弾後の無敵中でも踏みつけられる
- **GIVEN** プレイヤーが被弾後の無敵時間の最中である
- **WHEN** 落下しながら上からザコ敵を踏みつける
- **THEN** ザコ敵は倒される

### Requirement: ザコ敵との接触による被弾
システムは、プレイヤーが生存中のザコ敵と、上から踏みつける条件を満たさずに重なったとき、無敵でなければプレイヤーのHPを 1 減らし、プレイヤーを小さく上方向へ跳ね上げ、2 秒の無敵時間を設定しなければならない(SHALL)。ザコ敵はボスと違い、プレイヤーを押し戻さず、無敵の間は通り抜けられる。

#### Scenario: 横から接触して被弾
- **GIVEN** プレイヤーのHPが 3 で、無敵時間が 0 である
- **WHEN** ザコ敵の側面に接触する
- **THEN** HPが 2 になり、プレイヤーは小さく上方向へ跳ね上がり、無敵時間が 2 秒になる

#### Scenario: 無敵中は被弾しない
- **GIVEN** プレイヤーが被弾後の無敵時間の最中である
- **WHEN** ザコ敵と重なったまま更新が繰り返される
- **THEN** HPは追加では減らず、プレイヤーは押し戻されずに敵を通り抜けられる

#### Scenario: 無敵が終わると再び被弾する
- **GIVEN** 無敵時間が 0 になり、プレイヤーがザコ敵と重なっている
- **WHEN** 更新が実行される
- **THEN** HPが 1 減り、再び無敵時間が設定される

#### Scenario: HPが 0 になる
- **GIVEN** プレイヤーのHPが 1 で、無敵時間が 0 である
- **WHEN** ザコ敵に接触する
- **THEN** HPが 0 になり、プレイヤーは死亡した状態になる

### Requirement: 倒された敵の扱い
システムは、倒されたザコ敵を画面から消し、以後はプレイヤーと接触しない扱いにしなければならない(SHALL)。ザコ敵は、倒されたときに部品などをドロップしない。

#### Scenario: 倒された敵は消える
- **GIVEN** ザコ敵が倒された
- **WHEN** 画面を描画する
- **THEN** その敵は描画されない

#### Scenario: 倒された敵の位置を通過する
- **GIVEN** ザコ敵が倒されている
- **WHEN** プレイヤーが元の敵の位置を通過する
- **THEN** 被弾も跳ね返りも発生しない

#### Scenario: ドロップしない
- **GIVEN** ザコ敵が生存している
- **WHEN** そのザコ敵を踏みつけて倒す
- **THEN** 部品は出現しない

### Requirement: ザコ敵の表示
システムは、ザコ敵を、種類ごとに異なる色と目印を付けた図形で描画しなければならない(SHALL)。画像素材は使わない。

#### Scenario: 種類ごとの見分け
- **GIVEN** 異なる種類のザコ敵が画面内にいる
- **WHEN** 画面を描画する
- **THEN** 種類ごとに異なる色または目印で描画され、見分けられる

#### Scenario: 画面外の敵
- **GIVEN** ザコ敵がカメラの表示範囲の外にいる
- **WHEN** 画面を描画する
- **THEN** その敵は描画されず、近づいてカメラに入るとワールド座標に応じた位置に描画される

### Requirement: 再プレイで敵を初期状態に戻す
システムは、再プレイを開始するとき、倒されたザコ敵を含め、すべてのザコ敵を初期の位置と状態に戻さなければならない(SHALL)。

#### Scenario: 再プレイでの復活
- **GIVEN** プレイ中に一部のザコ敵を倒した
- **WHEN** クリアまたはゲームオーバーのあと、再プレイを開始する
- **THEN** すべてのザコ敵が、初期の位置で生存している
