# player-movement Specification

## Purpose

プレイヤーが地面の上に立ち、キー入力で左右に移動し、重力を受けながらジャンプして着地できるようにする。横スクロールアクションの基本操作を成立させる。

## Requirements

### Requirement: 地面とプレイヤーを表示する
システムは、画面に地面とプレイヤーを描画し、開始時にプレイヤーを地面の上に静止した状態で配置しなければならない(SHALL)。プレイヤーの素材が読み込まれている場合は画像で、読み込まれていない場合は四角形で描画する。

#### Scenario: ゲーム開始直後
- **GIVEN** ゲームが起動されている
- **WHEN** ゲームが開始される
- **THEN** 地面とプレイヤーが画面に表示され、プレイヤーは地面の上に立っている

#### Scenario: プレイヤーの素材がある場合
- **GIVEN** プレイヤーの素材が読み込まれている
- **WHEN** ゲームが開始される
- **THEN** プレイヤーは四角形ではなく画像で描画され、画像の下辺は地面の上辺に揃っている

#### Scenario: プレイヤーの素材がない場合
- **GIVEN** プレイヤーの素材が読み込まれていない
- **WHEN** ゲームが開始される
- **THEN** プレイヤーは四角形で描画され、プレイヤーは地面の上に立っている

### Requirement: 左右移動
システムは、左矢印キーまたは A キーで左へ、右矢印キーまたは D キーで右へプレイヤーを移動させなければならない(SHALL)。キーを離したときは水平方向に停止する。

#### Scenario: 右へ移動
- **GIVEN** プレイヤーが地面の上に立っている
- **WHEN** 右矢印キーまたは D キーを押し続ける
- **THEN** プレイヤーの x 座標は更新ごとに増加し続ける

#### Scenario: 左へ移動
- **GIVEN** プレイヤーが地面の上に立っている
- **WHEN** 左矢印キーまたは A キーを押し続ける
- **THEN** プレイヤーの x 座標は更新ごとに減少し続ける

#### Scenario: キーを離す
- **GIVEN** プレイヤーが右へ移動している
- **WHEN** すべての移動キーが離される
- **THEN** プレイヤーの x 座標は変化しなくなる

#### Scenario: 左右同時押し
- **GIVEN** プレイヤーが地面の上に立っている
- **WHEN** 左右の移動キーが同時に押されている
- **THEN** プレイヤーの x 座標は変化しない

### Requirement: ジャンプと重力
システムは、地面に接している間にスペースキーが押されたとき、プレイヤーを上方向へ跳ね上げなければならない(SHALL)。空中では重力により下向きの速度が増え、プレイヤーは放物線を描いて落下する。

#### Scenario: 地面でジャンプ
- **GIVEN** プレイヤーが地面に接している
- **WHEN** スペースキーを押す
- **THEN** プレイヤーは地面から離れて上昇し、頂点に達した後に下降する

#### Scenario: 空中での二重ジャンプ禁止
- **GIVEN** プレイヤーが空中にいる
- **WHEN** スペースキーを押す
- **THEN** ジャンプは発生せず、上向きの速度は与えられない

#### Scenario: 空中での水平移動
- **GIVEN** プレイヤーが空中にいる
- **WHEN** 右移動キーを押し続ける
- **THEN** プレイヤーは空中でも右へ移動する

### Requirement: 地面への着地
システムは、プレイヤーが地面の面を貫通しないようにし、落下して地面に達したときに着地させ、垂直速度を 0 にしなければならない(SHALL)。

#### Scenario: ジャンプ後の着地
- **GIVEN** プレイヤーがジャンプして空中にいる
- **WHEN** プレイヤーが地面の高さに達する
- **THEN** プレイヤーは地面の上で止まり、垂直速度は 0 になり、再びジャンプできる

#### Scenario: 長押しでの連続ジャンプ
- **GIVEN** プレイヤーが地面の上にいてスペースキーを押し続けている
- **WHEN** 着地する
- **THEN** 着地した更新、または次の更新で再びジャンプできる(ジャンプ入力は押下状態に基づく)

### Requirement: ワールドの両端
システムは、有限の幅を持つワールドを定義し、プレイヤーがワールドの左端・右端より外へ出ないようにしなければならない(SHALL)。

#### Scenario: 左端で左へ移動
- **GIVEN** プレイヤーがワールドの左端に接している
- **WHEN** 左移動キーを押し続ける
- **THEN** プレイヤーの x 座標は左端より小さくならない

#### Scenario: 右端で右へ移動
- **GIVEN** プレイヤーがワールドの右端に接している
- **WHEN** 右移動キーを押し続ける
- **THEN** プレイヤーの右辺はワールドの右端を超えない
