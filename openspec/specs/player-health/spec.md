# player-health Specification

## Purpose

プレイヤーに体力(HP)を持たせ、敵との接触や穴への落下で減り、尽きると敗北となるようにする。被弾後は一定時間の無敵時間を設けて、連続して被弾しないようにする。

## Requirements

### Requirement: HPの初期値と表示
システムは、プレイヤーのHPを 3 で開始し、画面左上の固定位置に現在のHPをハートの数で表示しなければならない(SHALL)。

#### Scenario: 開始時のHP
- **GIVEN** ゲームのプレイが開始された
- **WHEN** 最初の状態が作られる
- **THEN** プレイヤーのHPは 3 で、無敵時間は 0 である

#### Scenario: HPの表示
- **GIVEN** プレイヤーのHPが 2 である
- **WHEN** 画面を描画する
- **THEN** 画面左上の固定位置に、残りHPを示すハートが 2 個表示される

#### Scenario: スクロール中の表示位置
- **GIVEN** カメラが移動している
- **WHEN** 画面を描画する
- **THEN** HPの表示は画面上の同じ位置に留まる

### Requirement: ボスとの接触による被弾
システムは、プレイヤーが生存中のボスと、上から踏みつける条件を満たさずに重なったとき、無敵でなければプレイヤーのHPを 1 減らさなければならない(SHALL)。被弾したとき、プレイヤーを小さく上方向へ跳ね上げる。

#### Scenario: 横から接触して被弾
- **GIVEN** プレイヤーのHPが 3 で、無敵時間が 0 である
- **WHEN** 地面を歩いてボスの側面に接触する
- **THEN** HPが 2 になり、プレイヤーは小さく上方向へ跳ね上がる

#### Scenario: 踏みつけでは被弾しない
- **GIVEN** プレイヤーのHPが 3 で、無敵時間が 0 である
- **WHEN** 落下しながら上からボスを踏みつける
- **THEN** HPは 3 のまま変化しない

#### Scenario: 撃破済みのボスでは被弾しない
- **GIVEN** ボスが撃破されている
- **WHEN** プレイヤーが元のボスの位置を通過する
- **THEN** HPは変化しない

#### Scenario: 接触していない間
- **GIVEN** プレイヤーのHPが 3 である
- **WHEN** ボスに触れないまま更新が繰り返される
- **THEN** HPは変化しない

### Requirement: 被弾後の無敵時間
システムは、プレイヤーが被弾した直後に 2 秒間の無敵時間を設け、その間はボスに接触してもHPを減らしてはならない(SHALL)。無敵時間は更新ごとに減り、0 になると再び被弾する。

#### Scenario: 無敵時間の開始
- **GIVEN** プレイヤーのHPが 3 で、無敵時間が 0 である
- **WHEN** ボスの側面に接触して被弾する
- **THEN** 無敵時間が 2 秒に設定される

#### Scenario: 無敵中は連続して被弾しない
- **GIVEN** プレイヤーが被弾して無敵時間の最中である
- **WHEN** ボスと重なったまま更新が繰り返される
- **THEN** HPは追加では減らない

#### Scenario: 無敵時間の終了後
- **GIVEN** 被弾から 2 秒が経過して無敵時間が 0 になった
- **WHEN** 再びボスの側面に接触する
- **THEN** HPが 1 減り、再び無敵時間が設定される

#### Scenario: 無敵中でも踏みつけはできる
- **GIVEN** プレイヤーが無敵時間の最中である
- **WHEN** 落下しながら上からボスを踏みつける
- **THEN** ボスの体力が 1 減り、プレイヤーは上方向へ跳ね返る

### Requirement: 無敵中の点滅表示
システムは、無敵時間の間、プレイヤーを一定間隔(0.1 秒)で表示と非表示を切り替えて点滅させなければならない(SHALL)。無敵でない間は常に表示する。

#### Scenario: 無敵でないとき
- **GIVEN** プレイヤーの無敵時間が 0 である
- **WHEN** プレイヤーの表示/非表示を判定する
- **THEN** 常に表示される

#### Scenario: 無敵中の切り替え
- **GIVEN** プレイヤーの無敵時間が 2 秒である
- **WHEN** 0.1 秒ごとに残り時間が減りながら判定する
- **THEN** 表示と非表示が交互に切り替わる

#### Scenario: 無敵時間の終了
- **GIVEN** 無敵時間が 0 になった
- **WHEN** 判定する
- **THEN** 以後は常に表示される

### Requirement: HPが0で死亡する
システムは、プレイヤーのHPが 0 になったとき、プレイヤーを死亡した状態にしなければならない(SHALL)。HPは 0 を下回らない。

#### Scenario: 最後の1点で死亡
- **GIVEN** プレイヤーのHPが 1 で、無敵時間が 0 である
- **WHEN** ボスの側面に接触する
- **THEN** HPが 0 になり、プレイヤーは死亡した状態になる

#### Scenario: HPが 0 を下回らない
- **GIVEN** プレイヤーが死亡している
- **WHEN** さらに更新が実行される
- **THEN** HPは 0 のままである

#### Scenario: 生存中
- **GIVEN** プレイヤーのHPが 1 以上である
- **WHEN** 更新が実行される
- **THEN** プレイヤーは死亡した状態にならない

### Requirement: 穴への落下による被弾と復帰
システムは、プレイヤーが落下ライン(ステージの下端より下)を越えたとき、HPを 1 減らし、直前の安全な足場の位置へ戻さなければならない(SHALL)。戻された直後は無敵時間を設定し、速度は 0 にする。落下による被弾は、被弾後の無敵時間の最中でも発生する。

#### Scenario: 穴に落ちる
- **GIVEN** プレイヤーのHPが 3 で、穴の上を通って落下している
- **WHEN** プレイヤーが落下ラインを越える
- **THEN** HPが 2 になり、プレイヤーは直前の安全な足場の位置に戻され、速度は 0 で、無敵時間が設定される

#### Scenario: 無敵中でも落下は被弾になる
- **GIVEN** プレイヤーが被弾後の無敵時間の最中で、穴に落ちる
- **WHEN** プレイヤーが落下ラインを越える
- **THEN** HPが 1 減り、再び安全な足場に戻される

#### Scenario: 最後の1点で落ちる
- **GIVEN** プレイヤーのHPが 1 である
- **WHEN** 穴に落ちて落下ラインを越える
- **THEN** HPが 0 になり、プレイヤーは死亡した状態になる

#### Scenario: 足場の上で落下ラインに達しない
- **GIVEN** プレイヤーが地面や足場の上に立っている
- **WHEN** 更新が繰り返される
- **THEN** 落下ラインは越えず、HPは変化しない

### Requirement: 復帰直後の操作不能時間
システムは、穴から復帰した直後の 0.4 秒間、プレイヤーの操作を受け付けてはならない(SHALL)。キーを押し続けていても、復帰直後に再び穴へ落ちないようにするためである。

#### Scenario: 復帰直後に押し続けたキー
- **GIVEN** プレイヤーが穴に落ちて復帰した直後で、右移動キーが押され続けている
- **WHEN** 0.4 秒が経過する前の更新が実行される
- **THEN** プレイヤーは移動せず、復帰位置に留まる

#### Scenario: 操作不能時間の終了後
- **GIVEN** 復帰してから 0.4 秒が経過した
- **WHEN** 右移動キーが押されている状態で更新が実行される
- **THEN** プレイヤーは通常どおり右へ移動する

#### Scenario: 復帰直後のジャンプ入力
- **GIVEN** プレイヤーが穴に落ちて復帰した直後である
- **WHEN** 0.4 秒が経過する前にスペースキーを押す
- **THEN** ジャンプは発生しない

### Requirement: 安全な足場の記録
システムは、プレイヤーが地面・崖・浮島の上面に、足元の幅全体が支えられた状態で立っている間、その位置を復帰用の安全な位置として記録しなければならない(SHALL)。足元の一部しか支えられていない(穴や足場の端に立っている)間は、記録を更新しない。

#### Scenario: 足場の上で記録する
- **GIVEN** プレイヤーが地面の上に足元の幅全体で立っている
- **WHEN** 更新が実行される
- **THEN** その位置が安全な位置として記録される

#### Scenario: 穴の縁では記録しない
- **GIVEN** プレイヤーが穴の縁に立っていて、足元の一部が穴の上にある
- **WHEN** 更新が実行される
- **THEN** 安全な位置は更新されず、直前に記録された位置のままである

#### Scenario: 空中では記録しない
- **GIVEN** プレイヤーがジャンプして空中にいる
- **WHEN** 更新が実行される
- **THEN** 安全な位置は更新されない

#### Scenario: 穴を越えそこなって落ちる
- **GIVEN** プレイヤーが穴の手前の地面の縁からジャンプし、穴に落ちた
- **WHEN** 落下ラインを越える
- **THEN** 穴の縁より手前の、足元が完全に支えられていた位置に戻される
