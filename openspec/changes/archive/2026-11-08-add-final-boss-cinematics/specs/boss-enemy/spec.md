# Spec Delta

## MODIFIED Requirements

### Requirement: 撃破
システムは、ボスの体力が 0 になったとき、ボスを撃破された状態にし、画面から消さなければならない(SHALL)。撃破されたボスはプレイヤーと接触しない。ただし、最終ボスは、体力が 0 になってもすぐには撃破されず、撃破演出(約 3.5 秒)のあとで、撃破された状態になって画面から消える。

#### Scenario: 3 回の踏みつけで撃破
- **GIVEN** ボスの体力が 3 で、無敵時間をはさんで踏みつけを続ける
- **WHEN** 3 回目の踏みつけが成立する
- **THEN** ボスは撃破され、画面に描画されない

#### Scenario: 撃破後の接触
- **GIVEN** ボスが撃破されている
- **WHEN** プレイヤーが元のボスの位置を通過する
- **THEN** 押し戻しも跳ね返りも発生しない
