# Spec Delta

## MODIFIED Requirements

### Requirement: 脱出でクリア画面へ遷移する
システムは、脱出に成功したとき、プレイを終了してエンディング(約 12 秒の自動のアニメーション)を表示し、そのあとでクリア画面を表示しなければならない(SHALL)。クリア画面では、脱出に成功したことと、Enter キーでもう一度遊べることを表示する。

#### Scenario: 脱出に成功
- **GIVEN** プレイ中で、イカダが完成している
- **WHEN** プレイヤーが海へ到達して脱出が成立し、エンディングが終わる
- **THEN** クリア画面が表示される(脱出が成立した直後は、エンディングが表示される)

#### Scenario: クリア画面の表示内容
- **GIVEN** クリア画面が表示されている
- **WHEN** 画面を描画する
- **THEN** 脱出に成功したことと、Enter キーでもう一度遊べることが表示される

#### Scenario: クリア画面での入力
- **GIVEN** クリア画面が表示されている
- **WHEN** 移動キーやスペースキーを押す
- **THEN** ゲームの状態は変化しない

### Requirement: プレイ中のみゲームを進行させる
システムは、プレイ中の間だけ、プレイヤー・ボス・ザコ敵・部品の更新を行わなければならない(SHALL)。タイトル画面・エンディング・クリア画面・ゲームオーバー画面の間は、ゲームの世界を進行させない。

#### Scenario: クリア画面でのボスの移動
- **GIVEN** クリア画面が表示されている
- **WHEN** 複数回の更新が実行される
- **THEN** ボス・ザコ敵・プレイヤーの位置は変化しない

#### Scenario: ゲームオーバー画面でのボスの移動
- **GIVEN** ゲームオーバー画面が表示されている
- **WHEN** 複数回の更新が実行される
- **THEN** ボス・ザコ敵・プレイヤーの位置、HP、無敵時間は変化しない

#### Scenario: プレイ中の進行
- **GIVEN** プレイ中である
- **WHEN** 複数回の更新が実行される
- **THEN** ボスとザコ敵は定義された行動で動き、プレイヤーは入力に応じて動く

#### Scenario: エンディング中の世界
- **GIVEN** エンディングが表示されている
- **WHEN** 複数回の更新が実行される
- **THEN** ボス・ザコ敵・プレイヤーの位置、HP、無敵時間は変化しない
