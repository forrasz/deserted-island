# Spec Delta

## MODIFIED Requirements

### Requirement: 地面とプレイヤーを表示する
システムは、画面に地面とプレイヤーを描画し、開始時にプレイヤーを地面の上に静止した状態で配置しなければならない(SHALL)。プレイヤーの素材が読み込まれている場合は画像で、読み込まれていない場合は四角形で描画する。

#### Scenario: ゲーム開始直後
- **GIVEN** ゲームが起動されている
- **WHEN** ゲームが開始される
- **THEN** 地面とプレイヤーが画面に表示され、プレイヤーは地面の上に立っている

#### Scenario: プレイヤーの素材がある場合
- **GIVEN** プレイヤーの素材が読み込まれている
- **WHEN** ゲームが開始される
- **THEN** プレイヤーは四角形ではなく画像で描画され、画像の下辺は地面の上辺に揃っている

#### Scenario: プレイヤーの素材がない場合
- **GIVEN** プレイヤーの素材が読み込まれていない
- **WHEN** ゲームが開始される
- **THEN** プレイヤーは四角形で描画され、プレイヤーは地面の上に立っている
