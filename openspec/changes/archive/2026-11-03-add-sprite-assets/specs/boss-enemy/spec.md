# Spec Delta

## MODIFIED Requirements

### Requirement: ボスの配置と表示
システムは、ワールド上の決められた位置に、ボス「カクレモモジリ」を1体、地面の上に配置して描画しなければならない(SHALL)。ボスの素材が読み込まれている場合は画像で、読み込まれていない場合は図形で描画する。ボスは体力 3 で開始する。

#### Scenario: ゲーム開始直後
- **GIVEN** ゲームが開始された
- **WHEN** 最初の状態が作られる
- **THEN** ボスが 1 体、地面の上に存在し、体力は 3 である

#### Scenario: カメラ外のボス
- **GIVEN** ボスがカメラの表示範囲の外にいる
- **WHEN** 画面を描画する
- **THEN** ボスは画面上に描画されず、プレイヤーが近づいてカメラに入ると、ワールド座標に応じた位置に描画される

#### Scenario: ボスの素材がある場合
- **GIVEN** ボスの素材が読み込まれていて、ボスがカメラの表示範囲にいる
- **WHEN** 画面を描画する
- **THEN** ボスは図形ではなく画像で描画され、画像の下辺は地面の上辺に揃っている

#### Scenario: ボスの素材がない場合
- **GIVEN** ボスの素材が読み込まれていなくて、ボスがカメラの表示範囲にいる
- **WHEN** 画面を描画する
- **THEN** ボスは従来の図形で描画される
