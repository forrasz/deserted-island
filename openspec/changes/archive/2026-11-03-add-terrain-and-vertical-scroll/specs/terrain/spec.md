# Spec Delta

## Purpose

地面・穴・崖・浮島からなる地形を定義し、プレイヤーとの衝突(着地、壁、頭ぶつけ、浮島の通り抜け)を扱う。足場に登って上下に移動できるようにして、ジャンプに意味を持たせる。

## ADDED Requirements

### Requirement: 地形の構成
システムは、地形を、地面、崖、浮島の 3 種類で構成しなければならない(SHALL)。地面はステージの下端に沿って続き、途中に穴(地面のない区間)を持てる。崖は通り抜けられない壁(ブロック)、浮島は下から通り抜けられる薄い足場である。

#### Scenario: 地面と穴
- **GIVEN** 地面の途中に幅 150 の穴がある
- **WHEN** 穴の上の位置にプレイヤーが来る
- **THEN** その位置には支えとなる地面がなく、プレイヤーは落下する

#### Scenario: 地形を省略した世界
- **GIVEN** 地形(崖・浮島・穴)が定義されていない世界である
- **WHEN** プレイヤーを更新する
- **THEN** 従来と同じ、一定の高さの平らな地面として扱われる

### Requirement: 崖との衝突
システムは、崖を通り抜けられない壁として扱い、横から押し込まれたときは崖の側面で止め、上から落ちたときは上面に着地させ、下からジャンプで当たったときは下面で止めて上昇を打ち切らなければならない(SHALL)。

#### Scenario: 横から崖に当たる
- **GIVEN** プレイヤーが地面を歩いていて、前方に高さ 100 の崖がある
- **WHEN** 崖に向かって移動し続ける
- **THEN** プレイヤーの辺は崖の側面で止まり、崖の中に入らない

#### Scenario: 崖の上に着地する
- **GIVEN** プレイヤーが崖の上面より高い位置で、崖の上方にいる
- **WHEN** 落下して崖の上面の高さに達する
- **THEN** プレイヤーは崖の上面に着地し、垂直速度は 0 で、地面に接している状態になる

#### Scenario: 崖の下面に頭をぶつける
- **GIVEN** プレイヤーが崖の真下で、上向きの速度でジャンプしている
- **WHEN** プレイヤーの上辺が崖の下面に達する
- **THEN** プレイヤーは崖を通り抜けず、上昇が止まって下降に転じる

#### Scenario: 崖の上を歩く
- **GIVEN** プレイヤーが崖の上面に立っている
- **WHEN** 横へ移動する
- **THEN** 崖の端まで上面に立ったまま移動でき、端を越えると落下する

### Requirement: 浮島との衝突
システムは、浮島を、上から落ちてきたときだけ着地できる足場として扱わなければならない(SHALL)。下からのジャンプや横方向の移動では通り抜ける。

#### Scenario: 下からジャンプして浮島に乗る
- **GIVEN** プレイヤーが浮島の真下の地面に立っていて、浮島の上面が頭上 100 の高さにある
- **WHEN** ジャンプして浮島の上面より高く上がり、下降に転じる
- **THEN** 上昇中は浮島を通り抜け、下降して浮島の上面に達したときに着地する

#### Scenario: 横から浮島に触れる
- **GIVEN** プレイヤーが浮島と同じ高さを空中で水平に移動している
- **WHEN** 浮島の側面に触れる
- **THEN** 横方向では止められず、通り抜ける

#### Scenario: 浮島に着地しない場合
- **GIVEN** プレイヤーが浮島の上面より低い位置から落下している
- **WHEN** 浮島の下を通り過ぎる
- **THEN** 浮島には着地せず、そのまま下へ落ちる

#### Scenario: 浮島の上に立つ
- **GIVEN** プレイヤーが浮島に着地している
- **WHEN** 更新が繰り返される
- **THEN** プレイヤーは浮島の上面に立ったまま動かない

### Requirement: 足場の上でのジャンプ
システムは、崖・浮島の上面に立っている間も、地面に接している状態と同じに扱い、ジャンプできるようにしなければならない(SHALL)。空中での二重ジャンプは従来どおり禁止する。

#### Scenario: 浮島の上からジャンプ
- **GIVEN** プレイヤーが浮島の上に立っている
- **WHEN** スペースキーを押す
- **THEN** プレイヤーは上向きの速度でジャンプする

#### Scenario: 崖の上からジャンプ
- **GIVEN** プレイヤーが崖の上に立っている
- **WHEN** スペースキーを押す
- **THEN** プレイヤーは上向きの速度でジャンプする

#### Scenario: 空中ではジャンプできない
- **GIVEN** プレイヤーが足場から離れて空中にいる
- **WHEN** スペースキーを押す
- **THEN** 新たなジャンプは発生しない

### Requirement: 落下速度の上限
システムは、プレイヤーの落下速度に上限を設け、高い場所から落ちても足場や崖の上面をすり抜けないようにしなければならない(SHALL)。

#### Scenario: 長い落下
- **GIVEN** プレイヤーが高さ 1000 の位置から落下する
- **WHEN** 更新が繰り返される
- **THEN** 落下速度は上限を超えず、途中にある浮島の上面や地面に着地する(すり抜けない)

#### Scenario: 上面の薄い足場
- **GIVEN** プレイヤーが最大の落下速度で、薄い浮島の上に落ちる
- **WHEN** 更新が実行される
- **THEN** プレイヤーは浮島の上面に着地する
