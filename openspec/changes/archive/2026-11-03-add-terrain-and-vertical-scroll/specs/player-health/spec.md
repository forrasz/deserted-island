# Spec Delta

## ADDED Requirements

### Requirement: 穴への落下による被弾と復帰
システムは、プレイヤーが落下ライン(ステージの下端より下)を越えたとき、HPを 1 減らし、直前の安全な足場の位置へ戻さなければならない(SHALL)。戻された直後は無敵時間を設定し、速度は 0 にする。落下による被弾は、被弾後の無敵時間の最中でも発生する。

#### Scenario: 穴に落ちる
- **GIVEN** プレイヤーのHPが 3 で、穴の上を通って落下している
- **WHEN** プレイヤーが落下ラインを越える
- **THEN** HPが 2 になり、プレイヤーは直前の安全な足場の位置に戻され、速度は 0 で、無敵時間が設定される

#### Scenario: 無敵中でも落下は被弾になる
- **GIVEN** プレイヤーが被弾後の無敵時間の最中で、穴に落ちる
- **WHEN** プレイヤーが落下ラインを越える
- **THEN** HPが 1 減り、再び安全な足場に戻される

#### Scenario: 最後の1点で落ちる
- **GIVEN** プレイヤーのHPが 1 である
- **WHEN** 穴に落ちて落下ラインを越える
- **THEN** HPが 0 になり、プレイヤーは死亡した状態になる

#### Scenario: 足場の上で落下ラインに達しない
- **GIVEN** プレイヤーが地面や足場の上に立っている
- **WHEN** 更新が繰り返される
- **THEN** 落下ラインは越えず、HPは変化しない

### Requirement: 復帰直後の操作不能時間
システムは、穴から復帰した直後の 0.4 秒間、プレイヤーの操作を受け付けてはならない(SHALL)。キーを押し続けていても、復帰直後に再び穴へ落ちないようにするためである。

#### Scenario: 復帰直後に押し続けたキー
- **GIVEN** プレイヤーが穴に落ちて復帰した直後で、右移動キーが押され続けている
- **WHEN** 0.4 秒が経過する前の更新が実行される
- **THEN** プレイヤーは移動せず、復帰位置に留まる

#### Scenario: 操作不能時間の終了後
- **GIVEN** 復帰してから 0.4 秒が経過した
- **WHEN** 右移動キーが押されている状態で更新が実行される
- **THEN** プレイヤーは通常どおり右へ移動する

#### Scenario: 復帰直後のジャンプ入力
- **GIVEN** プレイヤーが穴に落ちて復帰した直後である
- **WHEN** 0.4 秒が経過する前にスペースキーを押す
- **THEN** ジャンプは発生しない

### Requirement: 安全な足場の記録
システムは、プレイヤーが地面・崖・浮島の上面に、足元の幅全体が支えられた状態で立っている間、その位置を復帰用の安全な位置として記録しなければならない(SHALL)。足元の一部しか支えられていない(穴や足場の端に立っている)間は、記録を更新しない。

#### Scenario: 足場の上で記録する
- **GIVEN** プレイヤーが地面の上に足元の幅全体で立っている
- **WHEN** 更新が実行される
- **THEN** その位置が安全な位置として記録される

#### Scenario: 穴の縁では記録しない
- **GIVEN** プレイヤーが穴の縁に立っていて、足元の一部が穴の上にある
- **WHEN** 更新が実行される
- **THEN** 安全な位置は更新されず、直前に記録された位置のままである

#### Scenario: 空中では記録しない
- **GIVEN** プレイヤーがジャンプして空中にいる
- **WHEN** 更新が実行される
- **THEN** 安全な位置は更新されない

#### Scenario: 穴を越えそこなって落ちる
- **GIVEN** プレイヤーが穴の手前の地面の縁からジャンプし、穴に落ちた
- **WHEN** 落下ラインを越える
- **THEN** 穴の縁より手前の、足元が完全に支えられていた位置に戻される
