# Spec Delta

## Purpose

スマホなどのタッチ操作の端末で、画面上のボタンと画面のタップを、キーボードと同じゲームの入力(左・右・ジャンプ・決定)として扱えるようにする。

## ADDED Requirements

### Requirement: 画面上の移動・ジャンプボタン
システムは、タッチ操作の端末で、画面の左側に「左」「右」のボタン、右側に「ジャンプ」のボタンを重ねて表示し、ボタンを押している間だけ、対応する入力(左移動・右移動・ジャンプ)を有効にしなければならない(SHALL)。ボタンから指を離したときは、その入力を無効にする。

#### Scenario: 右ボタンを押している間
- **GIVEN** プレイ中で、右ボタンを指で押している
- **WHEN** 更新が複数回実行される
- **THEN** すべての更新で右移動の入力が有効で、左移動とジャンプの入力は無効である

#### Scenario: 指を離す
- **GIVEN** 右ボタンを押していて、右移動の入力が有効である
- **WHEN** 指をボタンから離す
- **THEN** 次の更新から右移動の入力は無効になる

#### Scenario: ジャンプボタン
- **GIVEN** プレイ中で、プレイヤーが地面に立っている
- **WHEN** ジャンプボタンを押す
- **THEN** キーボードのジャンプキーを押したときと同じ入力になり、プレイヤーはジャンプする

### Requirement: 複数の指の同時操作
システムは、複数のボタンを別の指で同時に押せるようにしなければならない(SHALL)。ある指を離しても、押したままの別のボタンの入力は保たれる。

#### Scenario: 移動しながらジャンプ
- **GIVEN** 右ボタンを 1 本目の指で押している
- **WHEN** 2 本目の指でジャンプボタンを押す
- **THEN** 右移動とジャンプの入力が同時に有効になる

#### Scenario: 片方の指だけ離す
- **GIVEN** 右ボタンとジャンプボタンを別の指で押している
- **WHEN** ジャンプボタンの指だけを離す
- **THEN** 右移動の入力は有効なままで、ジャンプの入力だけが無効になる

### Requirement: ボタンの押しっぱなしを防ぐ
システムは、タッチ操作が中断されたとき(指が別のボタンや画面の外へ動いた・通話などでタッチが取り消された・ページが非表示になった・画面の向きが変わった)に、押されていたボタンの入力を無効にしなければならない(SHALL)。入力が有効なまま残ってはならない。

#### Scenario: 指がボタンの外へ動く
- **GIVEN** 右ボタンを押している
- **WHEN** 指を押したまま、ボタンの外へ動かす
- **THEN** 右移動の入力は無効になる

#### Scenario: タッチの取り消し
- **GIVEN** 右ボタンを押している
- **WHEN** システムの割り込みでタッチが取り消される
- **THEN** 右移動の入力は無効になる

#### Scenario: ページが非表示になる
- **GIVEN** 右ボタンを押している
- **WHEN** ページが非表示になる
- **THEN** すべてのボタンの入力が無効になる

### Requirement: 画面タップによる決定
システムは、タイトル画面・クリア画面・ゲームオーバー画面で、画面のどこかをタップしたときに、`Enter` キーと同じ決定の入力にしなければならない(SHALL)。プレイ中のタップは、決定の入力にしてはならない。

#### Scenario: タイトル画面でタップ
- **GIVEN** タイトル画面が表示されている
- **WHEN** 画面をタップする
- **THEN** 決定の入力が有効になり、ゲームが始まる

#### Scenario: ゲームオーバー画面でタップ
- **GIVEN** ゲームオーバー画面が表示されている
- **WHEN** 画面をタップする
- **THEN** 決定の入力が有効になり、最初からやり直せる

#### Scenario: プレイ中はタップで決定しない
- **GIVEN** プレイ中である
- **WHEN** 画面のボタン以外の場所をタップする
- **THEN** 決定の入力は有効にならない

#### Scenario: 押しっぱなしで連続して進まない
- **GIVEN** タイトル画面で画面を押し続けていて、ゲームが始まった
- **WHEN** 指を離さずにプレイ中になる
- **THEN** 決定は押したままの状態として扱われ、ゲームオーバーなどの次の画面が、指を離して押し直すまで決定されない

### Requirement: ボタンの表示条件
システムは、操作ボタンを、タッチ操作が主な入力である端末(指で操作する端末)でだけ表示し、マウスとキーボードの端末では表示してはならない(SHALL)。ボタンは、ゲーム画面の中の見える範囲を大きく隠さない大きさと位置にする。

#### Scenario: タッチ端末
- **GIVEN** タッチ操作が主な入力の端末でゲームを開く
- **WHEN** プレイ画面が表示される
- **THEN** 左・右・ジャンプのボタンが表示される

#### Scenario: PC
- **GIVEN** マウスとキーボードの端末でゲームを開く
- **WHEN** プレイ画面が表示される
- **THEN** ボタンは表示されず、キーボードで従来どおり遊べる

### Requirement: キーボード操作との併用
システムは、タッチの入力とキーボードの入力を同時に受け付け、どちらかが有効なら、その入力を有効にしなければならない(SHALL)。

#### Scenario: タッチとキーボードの合成
- **GIVEN** キーボードの右キーが押されていて、タッチのジャンプボタンも押されている
- **WHEN** 入力状態を作る
- **THEN** 右移動とジャンプの入力が有効である
