# Spec Delta

## MODIFIED Requirements

### Requirement: 練習用の的
システムは、闘技場の手前の、練習用のヤシの木(「palm-trees」の、西の柱のすぐ手前の 1 本)の近く(西の柱の西側の外、プレイヤーの頭より少し上の高さ)に、練習用の的を 1 つ置き、ヤシの実が当たったときに、反応(光る・音)を出さなければならない(SHALL)。的に当たっても、何のダメージ・効果もなく、何度でも当てられる。登場演出の前から、いつでも使える。

#### Scenario: 的に当てると反応する
- **GIVEN** 的の位置が決まっている
- **WHEN** ヤシの実が的に当たる
- **THEN** 的が反応の状態(光る)になり、一定時間(0.4 秒)後に戻る。ヤシの実は消える

#### Scenario: 何度でも当てられる
- **GIVEN** 的に 1 度当てた
- **WHEN** 続けて当てる
- **THEN** 毎回、反応し、的は壊れない

### Requirement: ヤシの実を拾う
システムは、プレイヤーが、落ちている・落ちてくる途中のヤシの実に触れたとき、手持ちが 2 個未満であれば、ヤシの実を拾い、手持ちを 1 個増やさなければならない(SHALL)。手持ちが 2 個のときは拾わず、地面に残す。手持ちの数は、ゲームオーバーや再プレイで 0 に戻る。

#### Scenario: 触れると拾う
- **GIVEN** 手持ちが 0 個で、地面にヤシの実がある
- **WHEN** プレイヤーが重なる
- **THEN** ヤシの実は地面から消え、手持ちが 1 個になる

#### Scenario: 持てる数の上限
- **GIVEN** 手持ちが 2 個である
- **WHEN** プレイヤーが別のヤシの実に重なる
- **THEN** 拾わず、地面に残り、手持ちは 2 個のままである

#### Scenario: 再プレイで 0 に戻る
- **GIVEN** 手持ちが 2 個で、ゲームオーバーになった
- **WHEN** 再プレイを始める
- **THEN** 手持ちは 0 個である

## REMOVED Requirements

### Requirement: ヤシの実の置き場所と補充
**Reason**: 地面の決まった位置に置く方式をやめ、ヤシの木から手に入れる方式(「palm-trees」)に変えるため。
**Migration**: ヤシの実は、ヤシの木の頭突き・闘技場の木へのヌシの突進で落ちる(「palm-trees」)。補充の時間(10 秒)は、ヤシの木の実が、再びなるまでの時間に引き継ぐ。
