# Design

## Context

直前の変更(`add-throw-animation`)で、`drawPlayer` が、手持ちが 1 個以上の間、手元(前へ 16 px・足元から表示の高さの 0.55・半径 7 px)にヤシの実を描き、投げる動きの傾きにも合わせている。投げた更新に、ヤシの実の弾は、手の位置から出る(ゲームの論理は、すぐに投げる)。

## Goals / Non-Goals

**Goals:**
- 持っているだけでは、実を描かない。
- 投げるときだけ、手元に実を描く。

**Non-Goals:**
- 投げるまでの「ため」(実を振りかぶる時間)を、ゲームの論理に入れること。ヤシの実は、これまでどおり、押した瞬間に出る。
- 投げる動きの傾き・弧の変更。

## Decisions

1. **手元の実は、投げた瞬間から `THROW_HAND_TIME = 0.1` 秒だけ。** `throwPose(t)` に `showCoconut: boolean`(`0 ≤ t < 0.1`)を加える。描画は、`handCoconut = overlay && pose.showCoconut` のときだけ、手元に実を描く(手持ちの数には、よらない)。
   - 0.1 秒は、弾が、手から離れて見えるまで(水平に約 40 px)の間である。この間は、手元の実と、飛び出した実が、近くで重なって見えるが、同じ実が、手から離れていくように見える。
   - 代案: 手元の実を、完全になくす → 「投げるとき」の手応え(手から実が離れる)が減るので、採らない。代案: 振りかぶりの時間を、ゲームの論理に入れ、実の出る時刻を遅らせる → 操作の反応が遅れ、これまでの調整(ヒットストップ・先行入力)にも関わるので、採らない。
2. **手持ちの数の表示は、画面の右上の表示のままにする**(持っていることが、手元で見えなくなる代わり)。
3. 位置・大きさ・傾きの変換は、前回のままにする(`THROW_HAND_X` ほか)。

## Risks / Trade-offs

- 実を持っていることが、プレイヤーの手元では分からなくなる。右上の表示(実の絵と「ヤシの実」の文字)で分かる。
- 0.1 秒だけの表示なので、気づきにくい。傾き・弧の動きと一緒に出るので、投げた感じは残る。
