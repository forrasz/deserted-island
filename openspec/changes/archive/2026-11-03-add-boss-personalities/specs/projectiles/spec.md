# Spec Delta

## Purpose

ボスが出す攻撃(直進弾・放物線の弾・衝撃波)を扱う。プレイヤーはよける(ジャンプ、位置取り)ことで防ぎ、触れると被弾する。

## ADDED Requirements

### Requirement: 弾と衝撃波の種類と動き
システムは、ボスの攻撃として、直進弾・放物線の弾・衝撃波の 3 種類を扱わなければならない(SHALL)。直進弾は水平に一定の速さで進む。放物線の弾は重力で落ちる。衝撃波は地面の上を水平に走る。

#### Scenario: 直進弾
- **GIVEN** 水平の速さ 260 で撃たれた直進弾がある
- **WHEN** 1 秒分の更新が実行される
- **THEN** 水平におよそ 260 だけ進み、高さは変わらない

#### Scenario: 放物線の弾
- **GIVEN** 上向きの速さ 650、水平の速さ 300 で投げられた放物線の弾がある
- **WHEN** 更新が繰り返される
- **THEN** 上へ昇ってから落ち、水平の位置は一定の速さで進み続ける

#### Scenario: 衝撃波
- **GIVEN** 毎秒 280 で右へ走る衝撃波がある
- **WHEN** 1 秒分の更新が実行される
- **THEN** 地面の上を水平におよそ 280 だけ進み、地面から離れない

### Requirement: 弾と衝撃波の消滅
システムは、弾と衝撃波を、寿命(直進弾 3 秒・衝撃波 2 秒)が尽きたとき、ステージの外へ出たとき、放物線の弾が地面に達したとき、プレイヤーに当たったときに消さなければならない(SHALL)。

#### Scenario: 寿命で消える
- **GIVEN** 出現してから 3 秒が経過した直進弾がある
- **WHEN** 更新が実行される
- **THEN** その弾は消える

#### Scenario: 地面に落ちて消える
- **GIVEN** 放物線の弾が落ちて地面の高さに達した
- **WHEN** 更新が実行される
- **THEN** その弾は消える

#### Scenario: ステージの外で消える
- **GIVEN** 弾がステージの左端または右端を越えた
- **WHEN** 更新が実行される
- **THEN** その弾は消える

### Requirement: 弾と衝撃波による被弾
システムは、プレイヤーが弾または衝撃波と重なったとき、無敵でなければプレイヤーのHPを 1 減らし、小さく上方向へ跳ね上げ、2 秒の無敵時間を設定し、その弾を消さなければならない(SHALL)。無敵の間は被弾せず、弾はプレイヤーを通り抜けて進み続ける。プレイヤーは弾を壊せず、踏んでも倒せない。

#### Scenario: 弾に当たる
- **GIVEN** プレイヤーのHPが 3 で、無敵時間が 0 である
- **WHEN** 直進弾がプレイヤーと重なる
- **THEN** HPが 2 になり、プレイヤーは小さく跳ね上がり、無敵時間が 2 秒になり、弾は消える

#### Scenario: 無敵中は被弾しない
- **GIVEN** プレイヤーが被弾後の無敵時間の最中である
- **WHEN** 弾がプレイヤーと重なる
- **THEN** HPは減らず、弾は消えずに進み続ける

#### Scenario: ジャンプで衝撃波をよける
- **GIVEN** 地面を走る衝撃波が、プレイヤーの足元へ近づいている
- **WHEN** プレイヤーが、衝撃波の高さより高くジャンプして通過を待つ
- **THEN** プレイヤーは被弾しない

#### Scenario: 踏んでも倒せない
- **GIVEN** 直進弾がある
- **WHEN** プレイヤーが落下しながら上から弾に重なる
- **THEN** 弾は倒されず、通常の接触として被弾する(無敵でなければ)

#### Scenario: 死亡する
- **GIVEN** プレイヤーのHPが 1 で、無敵時間が 0 である
- **WHEN** 弾に当たる
- **THEN** HPが 0 になり、死亡した状態になる

### Requirement: プレイ中のみ動き、再プレイで消える
システムは、弾と衝撃波を、プレイ中の間だけ動かし、タイトル・クリア・ゲームオーバー画面の間は動かしてはならない(SHALL)。再プレイを開始するとき、すべての弾と衝撃波を取り除かなければならない。

#### Scenario: ゲームオーバー画面では止まる
- **GIVEN** ゲームオーバー画面が表示されていて、弾が飛んでいる
- **WHEN** 複数回の更新が実行される
- **THEN** 弾の位置は変化しない

#### Scenario: 再プレイで消える
- **GIVEN** 弾や衝撃波が出現している状態で、ゲームオーバーになった
- **WHEN** 再プレイを開始する
- **THEN** ワールド上に弾も衝撃波も存在しない

### Requirement: 弾と衝撃波の表示
システムは、弾と衝撃波を、プレイヤーやボスと見分けられる色の図形で描画しなければならない(SHALL)。画像素材は使わない。画面外の弾は描画しない。

#### Scenario: 画面内の弾
- **GIVEN** 弾が画面内にある
- **WHEN** 画面を描画する
- **THEN** ワールド座標に応じた位置に、図形で描画される

#### Scenario: 画面外の弾
- **GIVEN** 弾がカメラの表示範囲の外にある
- **WHEN** 画面を描画する
- **THEN** 描画されない
