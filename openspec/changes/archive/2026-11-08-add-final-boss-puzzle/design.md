# Design

## Context

- ヌシは `Boss`(`src/core/boss.ts`)で、行動は `boss-scripts.ts` の `NUSHI_FORM1` / `NUSHI_FORM2`(往復 → 予備動作 → 突進 → 休み → 予備動作 → 弾 → ジャンプ+衝撃波 → 休み)。`stepBossScript(boss, ctx, dt)` が、1 更新ぶんの行動・移動(往復範囲の中に収める)・弾の生成を返す。体力が半分(6)以下になると、`stepBossScript` が変身に入る
- 踏みつけは `game.ts` の `resolveBossContact` が扱う。`bossFlags(boss)` の目印(`hidden`・`stompImmune`・`harmless` など)で分岐し、通常は `damageBoss`(体力 -1)。休みの間のかがみ(`restH`)は `bossRect` が当たり判定の高さを 100 にして実現している
- ステージの地形は `world.solids`(地面と崖)で、プレイヤーは `stepPlayer(…, world)` で衝突する。弾は `stepProjectile` で動き、`game.ts` で接触を解決する
- ヌシの闘技場: 往復範囲の左端 23810・幅 600・本体の幅 200(= 23810〜24610)。前後 100 を含めて、穴・崖・浮島のない平らな地面。その先に、ザコ敵 2 体(24730〜)と、海の手前の安全な区間(SEA_X-600 = 24960 から)がある

## Goals / Non-Goals

**Goals:**
- 「突進を柱に当てて気絶させる」を、既存の行動の流れ・踏みつけ・弾の仕組みの上に、少ない変更で足す
- 柱と気絶の判定を `src/core` の純粋関数にして、Vitest で確認する
- 柱を使わないと倒せず、かつ、詰み(倒せなくなる状態)が起きない

**Non-Goals:**
- 演出(登場・撃破・エンディング)、効果音・画像素材、ヌシ以外のボスの変更(proposal 参照)

## Decisions

### 1. 気絶は `Boss.stagger`(残り秒)で持つ
`stagger > 0` のあいだ、`stepBossScript` は、行動の流れを進めず(その場で動かず、弾も出さない)、`stagger` を `dt` ずつ減らす。0 になったら、行動の流れの最初(往復)から再開する。
- 理由: 行動の流れ(`step`・`t`)を保ったまま中断・再開するより、再開時に最初から始めるほうが単純で、「回復した」ことが分かりやすい
- `bossFlags(boss)` に `staggered`(`stagger > 0`)を足し、`crouch`(かがんで高さ 100)は、これで決める(休みでは、かがまない)。かがんだ矩形は、既存の `bossRect`(`restH`)の仕組みをそのまま使う
- 代替: 行動の流れに `stagger` という行動を足す。外から(突進の衝突で)割り込むので、流れの中の 1 ステップとして表すのは不自然

### 2. 柱への衝突は、突進(dash)の中で、往復範囲の端で判定する
柱は 2 本。西の柱は、ヌシの往復範囲の左端のすぐ外(柱の東の縁 = 範囲の左端)、東の柱は、ヌシの本体の右端のすぐ外(柱の西の縁 = 範囲の右端 + ヌシの幅)に置く。突進が、向かう側の範囲の端に達する(= 柱に当たる)ことを、衝突とみなす。
- `BossCtx` に `pillars: { west: number | null; east: number | null }`(立っている西の柱の東の縁と、東の柱の西の縁。なければ null)を足す。`stepBossScript` は、突進の更新で、西向きなら `x <= west + 誤差`、東向きなら `x + w >= east - 誤差` のとき、`stagger = NUSHI_STAGGER_TIME(6)` にして返す
- 理由: 柱とヌシの位置関係を「範囲の端 = 柱」と決めておけば、ヌシの更新が柱の矩形を知らなくても、判定が 1 つの比較で済む。範囲の幅 300 は、突進の距離(400)より短いので、反対側の端からの突進でも柱に届く
- `game.ts` は、ヌシの `stagger` が 0 → 正になった更新で、立っている柱を**両方とも**壊す(`alive = false`・`brokenT = 0`)。突進の向きの側だけを壊すと、踏んだあとにヌシの反対側(闘技場の中)へ跳ねたプレイヤーが、立っている反対側の柱とヌシに挟まれて出られなくなる。両方崩せば、出口が必ず開く
- 柱が 2 本ある理由: 1 本(西だけ)だと、踏んだあとにプレイヤーがヌシの東側へ回ると、立ったヌシ(高さ 250)に阻まれて西へ戻れず、誘い込めなくなる(詰み)。東にも柱があれば、どちら側にいても誘い込める

### 3. 柱は `GameState.pillars` で持ち、通れない地形・弾の遮断として扱う
`Pillar { side, x, y, w, h, alive, brokenT }`。ステージの配置(`Stage.pillars`)から作る(闘技場に 2 本: 西 `x = 23960`、東 `x = 24520`、どちらも `w = 60`・`h = 180`)。ヌシの往復範囲の中心より西にあれば `side = 'west'`、東にあれば `'east'`。
- プレイヤー: 立っている柱を、更新のたびに `world.solids` へ加えた世界(`solidsOf(world)` + 柱の矩形)で `stepPlayer` を呼ぶ。復帰位置の判定(`isFullySupported`)も同じ世界を使う
- 弾・衝撃波: 立っている柱の矩形と重なったものを、消す(`alive = false`)。ヌシの弾の高さ(最大 170)は柱(180)より低いので、すべて止まる
- ボーナスの広間は、柱とは無関係(広間の世界を使う)

### 4. 踏みつけの結果は、ヌシの状態で分ける
`bossFlags` に、ヌシ用の目印を足す:
- `bounceOnly`(気絶しておらず、変身中でもない最終ボス): 踏むと、プレイヤーは跳ね返るが、ボスの体力は減らず、被弾もしない(横から触れれば、従来どおり被弾・押し戻し)
- `staggered`: 踏むと、`damageBoss(boss, 4)`(体力 -4)で、`stagger` を `NUSHI_RECOVER_TIME`(0.5 秒)にする(起き上がりまでの猶予)。触れても被弾も押し戻しもしない(`harmless` と同じ扱いで、踏みつけだけダメージを入れる)。0.5 秒の間は、ボスの無敵時間(既存の 0.5 秒)で、続けてダメージを受けない
- 通常ボス 9 体は、これまでどおり(体力 -1)。`damageBoss` に、ダメージ量の引数(既定 1)を足す
- 変身(体力が 6 以下)は、既存の判定のまま。気絶中の踏みつけで体力が 4 になったときは、`stagger` が 0 になった次の更新で、変身に入る

### 4b. 起き上がりに、プレイヤーを巻き込まない
気絶が解けて立つと、高さが 100 → 250 に戻り、踏んだあとに頭上にいるプレイヤーが、立った姿の矩形の中に入ってしまう(押し戻されて被弾する)。これを避けるため:
- 踏んだあとは、すぐには立たず、0.5 秒のあいだ、かがんだまま待つ(跳ね返ったプレイヤーが離れる時間)
- 気絶が解けるとき(6 秒の経過・踏んだあとの 0.5 秒の経過)、プレイヤーが立った姿の矩形と重なっていれば、離れるまで、かがんだまま起き上がらない。`BossCtx.playerInside`(`game.ts` が、立った姿の矩形との重なりで決める)で判定する
- 変身に入るときは、気絶を即座に解く(変身中は触れても被弾せず、押し戻しもないので、重なっていても安全)

### 5. 柱の再生は、`stepGame` が毎更新で判定する
壊れた柱の `brokenT` を `dt` ずつ増やし、次をすべて満たしたとき、`alive = true` に戻す(`brokenT = 0`):
- ヌシが生きている
- `brokenT >= 8`
- どのボスも気絶していない
- 柱の矩形が、ボスの当たり判定の矩形とも、プレイヤーの矩形とも重ならない
- プレイヤーが柱の外側にいる(西の柱: `player.x + PLAYER_WIDTH <= pillar.x`、東の柱: `player.x >= pillar.x + pillar.w`)
- 理由: プレイヤーが闘技場の中にいる間に柱が立つと、閉じ込められる。外側にいるときだけ立てば、中にいる間は出口が開いたまま
- ヌシを倒した更新で、立っている柱をすべて壊し(`breakAllPillars`)、ヌシが死んでいるので、以後は再生しない(先へ進める。東の柱が残ってイカダへの道をふさぐことを防ぐ)

### 6. 闘技場の配置と、数値
- `BOSS_LEFTS[9] = 24020`(西の柱の東の縁)。ヌシの定義の `rangeWidth` を 600 → 300 にする(本体の右端は 24520)。西の柱: `x = 23960`〜24020、東の柱: `x = 24520`〜24580。ヌシの範囲(前後 100 を含む)は 23920〜24620 で、2 本の柱を含めて、平らな地面。ザコ敵(24730〜)・海の手前の安全な区間(24960〜)とは重ならない
- 数値は `config.ts` に置く: `FINAL_PILLAR_WIDTH = 60`・`FINAL_PILLAR_HEIGHT = 180`・`NUSHI_STAGGER_TIME = 6`・`NUSHI_STAGGER_DAMAGE = 4`・`PILLAR_REGROW_TIME = 8`
- 検査(`stage-check.ts`): 柱が 2 本あること、西の柱の東の縁がヌシの範囲の左端と、東の柱の西の縁が本体の右端と一致すること、柱とヌシの範囲(前後 100)が平らな地面の上にあること、範囲の幅が突進の距離以下であること

### 7. 描画
- 柱: 灰色の石の柱(矩形)に、ひびの線を数本。壊れている間は描かない
- 気絶したヌシ: かがんだ矩形(既存の `bossRect`)に、頭上の「目を回す」印(星)を表示する。通常の状態のヌシは、これまでどおり
- 気絶中の残り時間は表示しない(ヒントは出さない)

### 8. 確認
Vitest(気絶・踏みつけのダメージ・柱の衝突と再生・弾の遮断・柱の地形としての動き・ステージ検査)と、実ブラウザ(柱の手前に立ってヌシの突進を誘い、柱が壊れて気絶し、踏んで 3 回で倒せること。柱を使わず踏むだけでは倒せないこと)で確認する。

## Risks / Trade-offs

- **難しすぎる・簡単すぎる**: 柱の手前に立てば、弾も衝撃波も防げるので、戦いはほぼ安全になる。倒すまでに約 3 周期(1 周期は約 8 秒)かかり、気絶から踏むまでの間に近づく動作(約 100 px)が、緊張の中心になる。実際に遊んで、気絶の時間・ダメージ量・再生の時間を調整する(数値を変えたら spec も更新する)
- **詰みの防止**: 柱を東西に 1 本ずつ置き、どちら側にいても誘い込めるようにする(1 本だと、ヌシの反対側に取り残される)。再生は外側にいるときだけなので、闘技場の中に閉じ込められない。ヌシを倒したら柱をすべて崩して、出口をふさがない。気絶中のヌシ(高さ 100)は、ジャンプ(約 140)で越えられる
- **既存テストの書き換え**: ヌシを「休みの間に踏む」前提のテストが、多数ある(`boss-final.test.ts` など)。気絶の状態を直接作って踏むテストへ置き換える
- **無敵モード**: 無敵のときも、気絶中の踏みつけでダメージを与えられる。柱を使わない限り、倒せない(仕様どおり)
