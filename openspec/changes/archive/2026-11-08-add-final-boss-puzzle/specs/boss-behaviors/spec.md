# Spec Delta

## MODIFIED Requirements

### Requirement: 踏めない状態と触れない状態
システムは、ボスの特定の状態を、プレイヤーが踏んでもダメージを与えられない状態(踏めない)、またはプレイヤーが触れても被弾しない状態(触れない)にしなければならない(SHALL)。「もぐっている」は、踏めず、触れない。「転がっている」は、踏めず、触れると被弾する。「変身中」は、踏んでもダメージがなく、触れても被弾しない。最終ボスは、気絶していない通常の状態では、踏んでもダメージがなく(プレイヤーは跳ね返るだけ)、触れると被弾する。最終ボスの「気絶中」は、踏めて(ダメージが大きい)、触れても被弾しない。

#### Scenario: もぐっている間
- **GIVEN** ボスが地面にもぐっている
- **WHEN** プレイヤーが上から重なる、または横から重なる
- **THEN** ボスの体力は減らず、プレイヤーは被弾せず、押し戻されもしない

#### Scenario: 転がっている間に踏む
- **GIVEN** ボスが転がっている
- **WHEN** プレイヤーが落下しながら上から重なる
- **THEN** ボスの体力は減らず、プレイヤーは踏みつけの跳ね返りを得ず、通常の接触として扱われる(無敵でなければ被弾する)

#### Scenario: 変身中に踏む
- **GIVEN** 最終ボスが変身中である
- **WHEN** プレイヤーが落下しながら上から重なる
- **THEN** ボスの体力は減らず、プレイヤーは上方向へ跳ね返り、被弾しない

#### Scenario: 通常の状態では踏める
- **GIVEN** 最終ボス以外のボスが往復している(踏めない状態ではない)
- **WHEN** プレイヤーが落下しながら上から重なる
- **THEN** ボスの体力が 1 減る
