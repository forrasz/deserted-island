# Spec Delta

## Purpose

ゲームの脱出条件を実現する。必要な部品がそろうとイカダが完成し、完成したイカダでワールド右端の海へ出ると脱出に成功する。イカダがない間は海へ出られないようにして、部品集めに意味を持たせる。

## ADDED Requirements

### Requirement: イカダの完成
システムは、所持しているイカダの部品の数が必要数(1 個)以上になったとき、イカダを完成状態にしなければならない(SHALL)。完成した状態は、プレイが続く限り保たれる。

#### Scenario: 部品が足りない間
- **GIVEN** ゲームが開始された直後で、所持数が 0 である
- **WHEN** 更新が実行される
- **THEN** イカダは未完成である

#### Scenario: 必要数をそろえる
- **GIVEN** 所持数が 0 で、地面に部品がありプレイヤーと重なっている
- **WHEN** 更新が実行されて部品が拾得される
- **THEN** 所持数が 1 になり、同じ更新のうちにイカダが完成状態になる

#### Scenario: 完成後
- **GIVEN** イカダが完成している
- **WHEN** 更新が繰り返される
- **THEN** イカダは完成状態のままである

### Requirement: イカダの状態表示
システムは、画面の固定位置にイカダの状態(未完成 / 完成)を表示しなければならない(SHALL)。イカダが完成したときは、海へ向かうことを促す案内を表示する。

#### Scenario: 開始時の表示
- **GIVEN** ゲームのプレイが開始された
- **WHEN** 画面を描画する
- **THEN** イカダが未完成であることが画面に表示される

#### Scenario: 完成後の表示
- **GIVEN** イカダが完成している
- **WHEN** 画面を描画する
- **THEN** イカダが完成したこと、および海へ向かう案内が画面に表示される

### Requirement: 海の配置
システムは、ワールドの右端側に、地面の代わりに海の領域を設けなければならない(SHALL)。海はワールドの右端まで続き、海の開始位置の手前は砂浜(通常の地面)とする。

#### Scenario: 海の表示
- **GIVEN** カメラがワールドの右端付近まで移動している
- **WHEN** 画面を描画する
- **THEN** 画面の右側に、地面とは異なる見た目の海が表示される

#### Scenario: 海の手前の地面
- **GIVEN** プレイヤーが海の開始位置より手前にいる
- **WHEN** 画面を描画する
- **THEN** 海の開始位置までは、通常の地面として描画される

### Requirement: イカダ未完成時は海へ入れない
システムは、イカダが完成するまで、プレイヤーが海の領域へ入れないようにしなければならない(SHALL)。プレイヤーは海の開始位置の手前で止まり、海へ出られない理由を示す案内を表示する。

#### Scenario: 砂浜で止まる
- **GIVEN** イカダが未完成で、プレイヤーが海の手前の砂浜にいる
- **WHEN** 右移動キーを押し続ける
- **THEN** プレイヤーの右辺は海の開始位置を超えず、脱出は成立しない

#### Scenario: ジャンプでも越えられない
- **GIVEN** イカダが未完成で、プレイヤーが海の手前にいる
- **WHEN** 右移動キーを押しながらジャンプする
- **THEN** 空中でもプレイヤーの右辺は海の開始位置を超えない

#### Scenario: 案内の表示
- **GIVEN** イカダが未完成で、プレイヤーが海の開始位置に接している
- **WHEN** 画面を描画する
- **THEN** 海へ出るにはイカダが必要であることを示す案内が表示される

#### Scenario: 離れると案内が消える
- **GIVEN** イカダが未完成で、プレイヤーが海から離れている
- **WHEN** 画面を描画する
- **THEN** 海に関する案内は表示されない

### Requirement: イカダ完成後の脱出
システムは、イカダが完成している状態でプレイヤーが海の領域に到達したとき、脱出に成功したと判定しなければならない(SHALL)。

#### Scenario: 海へ到達
- **GIVEN** イカダが完成していて、プレイヤーが海の手前にいる
- **WHEN** 右へ進み、プレイヤーの右辺が海の開始位置に達する
- **THEN** 脱出に成功したと判定される

#### Scenario: イカダ未完成では判定されない
- **GIVEN** イカダが未完成で、プレイヤーが海の開始位置に接している
- **WHEN** 更新が繰り返される
- **THEN** 脱出に成功したとは判定されない

#### Scenario: 部品を拾った直後に海へ接している場合
- **GIVEN** プレイヤーが海の開始位置に接していて、部品を拾得してイカダが完成した
- **WHEN** 部品を拾得した更新、またはその次の更新が実行される
- **THEN** 遅くとも次の更新までに、脱出に成功したと判定される
