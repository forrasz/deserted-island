# Spec Delta

## Purpose

ゲーム全体の進行(タイトル、プレイ、クリア)と画面の切り替えを管理し、起動から脱出、再プレイまでを通して遊べるようにする。

## ADDED Requirements

### Requirement: タイトル画面から開始する
システムは、起動した直後にタイトル画面を表示し、Enter キーが押されたときにプレイを開始しなければならない(SHALL)。タイトル画面の間は、ゲームの世界(プレイヤー・ボス・部品)を進行させない。

#### Scenario: 起動直後
- **GIVEN** ゲームが起動された
- **WHEN** 最初のフレームを描画する
- **THEN** タイトル画面が表示され、ゲーム名と、Enter キーで始めることを示す案内、基本操作の説明が表示される

#### Scenario: Enter キーで開始
- **GIVEN** タイトル画面が表示されている
- **WHEN** Enter キーを押す
- **THEN** プレイが開始され、プレイヤーは開始位置にいて、所持数は 0、ボスは体力 3 で存在する

#### Scenario: タイトル画面での他のキー
- **GIVEN** タイトル画面が表示されている
- **WHEN** 移動キーやスペースキーを押す
- **THEN** プレイは開始されず、タイトル画面のままである

### Requirement: 決定キーは押した瞬間にのみ反応する
システムは、Enter キーを押し続けていても、1 回の押下として扱い、画面の遷移を連続して起こさないようにしなければならない(SHALL)。

#### Scenario: 押しっぱなし
- **GIVEN** タイトル画面で Enter キーが押された結果、プレイが開始された
- **WHEN** Enter キーを押し続ける
- **THEN** プレイヤーは動かず(Enter はプレイ中の入力として影響せず)、画面の遷移も起こらない

#### Scenario: 離してから押し直す
- **GIVEN** クリア画面が表示されていて、Enter キーが離されている
- **WHEN** Enter キーを押す
- **THEN** 再プレイが開始される

### Requirement: 脱出でクリア画面へ遷移する
システムは、脱出に成功したとき、プレイを終了してクリア画面を表示しなければならない(SHALL)。クリア画面では、脱出に成功したことと、Enter キーでもう一度遊べることを表示する。

#### Scenario: 脱出に成功
- **GIVEN** プレイ中で、イカダが完成している
- **WHEN** プレイヤーが海へ到達して脱出が成立する
- **THEN** クリア画面が表示される

#### Scenario: クリア画面の表示内容
- **GIVEN** クリア画面が表示されている
- **WHEN** 画面を描画する
- **THEN** 脱出に成功したことと、Enter キーでもう一度遊べることが表示される

#### Scenario: クリア画面での入力
- **GIVEN** クリア画面が表示されている
- **WHEN** 移動キーやスペースキーを押す
- **THEN** ゲームの状態は変化しない

### Requirement: 再プレイで初期状態に戻す
システムは、クリア画面で Enter キーが押されたとき、ゲームの状態をすべて初期状態に戻してプレイを再開しなければならない(SHALL)。前回のプレイの結果は引き継がない。

#### Scenario: 再プレイの開始
- **GIVEN** クリア画面が表示されている
- **WHEN** Enter キーを押す
- **THEN** プレイが開始され、プレイヤーは開始位置にいて、所持数は 0、イカダは未完成、ボスは体力 3 で存在し、ドロップ済みの部品は残っていない

#### Scenario: 何度でも繰り返せる
- **GIVEN** 1 回目のプレイをクリアして再プレイを開始した
- **WHEN** 再び脱出に成功する
- **THEN** 再度クリア画面が表示され、さらに再プレイもできる

### Requirement: プレイ中のみゲームを進行させる
システムは、プレイ中の間だけ、プレイヤー・ボス・部品の更新を行わなければならない(SHALL)。タイトル画面とクリア画面の間は、ゲームの世界を進行させない。

#### Scenario: クリア画面でのボスの移動
- **GIVEN** クリア画面が表示されている
- **WHEN** 複数回の更新が実行される
- **THEN** ボスやプレイヤーの位置は変化しない

#### Scenario: プレイ中の進行
- **GIVEN** プレイ中である
- **WHEN** 複数回の更新が実行される
- **THEN** ボスは往復し、プレイヤーは入力に応じて動く
