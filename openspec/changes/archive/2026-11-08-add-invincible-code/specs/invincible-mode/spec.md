# Spec Delta

## Purpose

隠しコマンド「上上下下左右左右BA」で入る無敵モードを定める。無敵の間は敵・ボス・弾・石のダメージを受けず、やり直しで解除される。

## ADDED Requirements

### Requirement: 隠しコマンドの入力
システムは、キーボードで `↑` `↑` `↓` `↓` `←` `→` `←` `→` `B` `A` の順にキーを押したとき、無敵モードをオンにしなければならない(SHALL)。コマンドは、タイトル画面とプレイ中に受け付ける。途中で順番と違うキーを押したときは、入力の進み具合を最初に戻す(違うキーが最初の `↑` なら、1 つ目として数える)。キーを押しっぱなしにしたことによる繰り返しは、1 回として数える。

#### Scenario: 正しい順番
- **GIVEN** プレイ中で、無敵モードはオフである
- **WHEN** `↑ ↑ ↓ ↓ ← → ← → B A` を順に押す
- **THEN** 無敵モードがオンになる

#### Scenario: 途中で間違える
- **GIVEN** `↑ ↑ ↓ ↓ ←` まで押した
- **WHEN** `↑` ではなく `B` を押し、続けて `→ ← → B A` を押す
- **THEN** 無敵モードはオンにならない(`B` で最初に戻っているため)

#### Scenario: 間違えたあとにやり直す
- **GIVEN** `↑ ↑ ↓` まで押したあと、`→` を押して間違えた
- **WHEN** 最初から `↑ ↑ ↓ ↓ ← → ← → B A` を押す
- **THEN** 無敵モードがオンになる

#### Scenario: 間違えたキーが最初のキー
- **GIVEN** `↑ ↑` まで押した
- **WHEN** `↑` をもう一度押し(3 つ目の `↑` は、最初に戻って 1 つ目として数えられる)、続けて `↑ ↓ ↓ ← → ← → B A` を押す
- **THEN** 3 つ目と 4 つ目の `↑` で 2 つぶんが数えられ、続く入力でコマンドが完成して、無敵モードがオンになる

#### Scenario: 押しっぱなし
- **GIVEN** `↑` を押しっぱなしにして、キーの繰り返しが何度も発生する
- **WHEN** 繰り返しの入力を受け取る
- **THEN** 2 つ目の `↑` として数えられず、離して押し直したときだけ 2 つ目として数える

#### Scenario: タイトル画面での入力
- **GIVEN** タイトル画面である
- **WHEN** コマンドを入力する
- **THEN** 無敵モードがオンになり、そのあとにスタートで始まるプレイでも、オンのままである

#### Scenario: 受け付けない画面
- **GIVEN** ゲームオーバー画面またはクリア画面である
- **WHEN** コマンドを入力する
- **THEN** 無敵モードはオンにならない

#### Scenario: 画面の遷移でやり直し
- **GIVEN** `↑ ↑ ↓ ↓ ← → ← →` まで押したあと、決定でゲームが始まった
- **WHEN** `B A` を押す
- **THEN** 入力の進み具合は画面の遷移で最初に戻っているため、無敵モードはオンにならない

### Requirement: 無敵モードの効果
システムは、無敵モードがオンの間、ザコ敵・ボス・ボスの弾と衝撃波・ボーナスステージの石に触れても、プレイヤーがダメージを受けないようにしなければならない(SHALL)。HPは減らず、硬直もせず、被弾後の無敵時間(点滅)も始めない。穴に落ちたときは、従来どおり直前の安全な足場へ戻されるが、HPは減らない。敵やボスを踏んで倒すこと、ボスの体で押し戻されること、ハートでHPを回復することは、従来どおりである。

#### Scenario: 敵に触れる
- **GIVEN** 無敵モードがオンで、プレイヤーのHPが 5 である
- **WHEN** ザコ敵に横から触れる
- **THEN** HPは 5 のままで、無敵時間(点滅)は始まらない

#### Scenario: ボスと弾
- **GIVEN** 無敵モードがオンである
- **WHEN** ボスに横から触れ、ボスの弾と衝撃波に当たる
- **THEN** HPは減らない。ボスの体には押し戻され、通り抜けられない

#### Scenario: 石
- **GIVEN** 無敵モードがオンで、ボーナスステージの中である
- **WHEN** 石に触れる
- **THEN** HPは減らず、硬直もせず、石は消えずに通り過ぎる

#### Scenario: 穴に落ちる
- **GIVEN** 無敵モードがオンで、HPが 5 である
- **WHEN** 穴に落ちる
- **THEN** 直前の安全な足場へ戻され、HPは 5 のままである

#### Scenario: 踏みつけは従来どおり
- **GIVEN** 無敵モードがオンである
- **WHEN** 上からボスを踏みつける
- **THEN** ボスの体力が 1 減り、プレイヤーは跳ね返る

#### Scenario: HPの回復
- **GIVEN** 無敵モードがオンで、ボーナスステージの中で、HPが 3 である
- **WHEN** ハートに触れる
- **THEN** HPが 4 になる

#### Scenario: オフのときは従来どおり
- **GIVEN** 無敵モードがオフである
- **WHEN** ザコ敵に横から触れる
- **THEN** HPが 1 減り、無敵時間が始まる

### Requirement: 無敵モードの解除
システムは、無敵モードを、コマンドをもう一度入力してもオフにしてはならず(SHALL)、ゲームオーバー画面またはクリア画面から決定でやり直したときに、オフに戻さなければならない(SHALL)。タイトル画面からスタートしたときは、オンのまま引き継ぐ。

#### Scenario: もう一度入力しても解除されない
- **GIVEN** 無敵モードがオンである
- **WHEN** もう一度コマンドを入力する
- **THEN** 無敵モードはオンのままである

#### Scenario: クリアからやり直す
- **GIVEN** 無敵モードがオンのままクリアした
- **WHEN** 決定でやり直す
- **THEN** 新しいプレイは、無敵モードがオフで始まる

#### Scenario: タイトルからスタート
- **GIVEN** タイトル画面で無敵モードをオンにした
- **WHEN** 決定でスタートする
- **THEN** プレイは無敵モードがオンのまま始まる

### Requirement: 無敵モードの表示
システムは、無敵モードがオンの間、画面に「無敵モード」と表示し、プレイヤーを金色で描画しなければならない(SHALL)。タイトル画面でオンにしたときも、「無敵モード」と表示する。オフのときは、どちらも表示しない。

#### Scenario: プレイ中
- **GIVEN** 無敵モードがオンでプレイ中である
- **WHEN** 画面を描画する
- **THEN** 「無敵モード」の表示があり、プレイヤーは金色で描かれ、被弾の点滅はしない

#### Scenario: タイトル画面
- **GIVEN** タイトル画面で無敵モードをオンにした
- **WHEN** 画面を描画する
- **THEN** 「無敵モード」と表示される

#### Scenario: オフのとき
- **GIVEN** 無敵モードがオフである
- **WHEN** 画面を描画する
- **THEN** 「無敵モード」の表示はなく、プレイヤーは通常の色で描かれる
