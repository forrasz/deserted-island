# Proposal

## Why

無人島脱出ゲームの実装を始めるにあたり、ブラウザで動く横スクロール2Dアクションの最小の土台がまだ存在しない。
敵・アイテム・イカダなどのゲーム要素を載せる前に、「動かせるプレイヤーが地面の上で動き、カメラが追従する」状態を作り、以降の変更が積み上がる基盤を確立する。

## What Changes

- TypeScript + Vite + HTML5 Canvas のプロジェクトを新規にセットアップする(Phaser は使わない)
- 固定タイムステップ(60FPS)のゲームループを実装する
- 画面に地面とプレイヤー(四角形)を描画する
- 矢印キー / A・D で左右移動、スペースでジャンプ(重力あり、地面に着地)を実装する
- プレイヤーに追従して横スクロールするカメラを実装する
- ゲームロジック(物理・移動・カメラ計算)は Canvas / DOM に依存しない純粋な TypeScript とし、Vitest でテストする
- **含めないもの**: 敵、アイテム、サウンド、イカダ・クリア条件、タイトル等のシーン遷移

## Capabilities

### New Capabilities
- `game-loop`: 固定タイムステップ(60FPS)で更新と描画を回すゲームループ
- `player-movement`: 入力による左右移動とジャンプ、重力、地面との接触、プレイヤーと地面の描画
- `camera-follow`: プレイヤーに追従して横スクロールするカメラと、ワールド座標から画面座標への変換

## Impact

- 新規コード: `package.json`、`tsconfig.json`、`vite.config.ts`、`index.html`、`src/` 配下(ロジック層・描画/入力アダプタ層)
- 新規依存関係: `typescript`、`vite`、`vitest`(開発依存のみ。実行時依存なし)
- プロジェクト文脈(`openspec/config.yaml`)との差分: 文脈には Phaser 3 とあるが、本変更の指示により Canvas を採用する。`config.yaml` の更新は本変更に含めず、レビュー時に判断する
