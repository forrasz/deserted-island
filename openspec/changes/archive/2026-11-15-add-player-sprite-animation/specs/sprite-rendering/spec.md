# Spec Delta

## MODIFIED Requirements

### Requirement: 当たり判定の矩形への合わせ方
システムは、キャラクターやオブジェクトの画像を、当たり判定の矩形の高さに合わせ、縦横比を保って拡大縮小し、矩形の水平方向の中央、下辺に揃えて描画しなければならない(SHALL)。当たり判定の矩形そのものは画像によって変化させない。ただし、プレイヤーのアニメーション(スプライトシートのコマ)は、「player-animation」の定める大きさ(キャラクターの高さ 70 px、足元を矩形の下辺の中央にそろえる)で描く。

#### Scenario: 縦長の画像
- **GIVEN** 当たり判定の矩形が幅 40・高さ 56 で、画像が幅 100・高さ 200 である
- **WHEN** 描画位置を計算する
- **THEN** 画像は高さ 56・幅 28 で、矩形の水平中央に、下辺を矩形の下辺に揃えて描画される

#### Scenario: 横長の画像
- **GIVEN** 当たり判定の矩形が幅 80・高さ 100 で、画像が幅 400・高さ 200 である
- **WHEN** 描画位置を計算する
- **THEN** 画像は高さ 100・幅 200 で、矩形の水平中央に、下辺を矩形の下辺に揃えて描画され、矩形の左右にはみ出す

#### Scenario: 足元が地面に揃う
- **GIVEN** プレイヤーが地面の上に立っている
- **WHEN** プレイヤーの画像を描画する
- **THEN** 画像の下辺は地面の上辺に揃う

#### Scenario: 当たり判定は変わらない
- **GIVEN** 画像素材が読み込まれている
- **WHEN** プレイヤーがボスを踏みつける、または側面に接触する
- **THEN** 判定は画像の大きさではなく、従来の矩形で行われ、結果は素材がない場合と同じになる
