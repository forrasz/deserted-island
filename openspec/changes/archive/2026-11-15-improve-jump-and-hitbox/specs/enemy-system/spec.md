# Spec Delta

## ADDED Requirements

### Requirement: ザコ敵の被弾判定は見た目より小さい
システムは、プレイヤーとの被弾の判定に、ザコ敵の見た目(幅・高さ 40)より小さい矩形(幅・高さ 32)を使わなければならない(SHALL)。被弾判定の矩形は、ザコ敵の下辺と左右の中心をそろえる(左右に 4 px ずつ、上に 8 px 小さい)。踏みつけの判定には、見た目の矩形を使い、変えない。

#### Scenario: 被弾判定の大きさと位置
- **GIVEN** ザコ敵が x = 500、y = 300 にいる(見た目の矩形が 500〜540、300〜340)
- **WHEN** 被弾判定の矩形を調べる
- **THEN** 矩形は x = 504〜536、y = 308〜340(幅・高さ 32)である

#### Scenario: 掠っただけでは被弾しない
- **GIVEN** プレイヤーが、ザコ敵の横に、見た目の矩形が 6 px 重なる位置にいて、被弾判定どうしは重なっていない
- **WHEN** 更新が実行される
- **THEN** 被弾せず、ザコ敵も倒れない

#### Scenario: 十分に重なると被弾する
- **GIVEN** プレイヤーが、ザコ敵の横に、被弾判定どうしが重なる位置にいる
- **WHEN** 更新が実行される
- **THEN** 無敵でなければ、被弾する

## MODIFIED Requirements

### Requirement: ザコ敵との接触による被弾
システムは、プレイヤーの被弾判定が、生存中のザコ敵の被弾判定と、上から踏みつける条件を満たさずに重なったとき、無敵でなければプレイヤーのHPを 1 減らし、プレイヤーを小さく上方向へ跳ね上げ、2 秒の無敵時間を設定しなければならない(SHALL)。ザコ敵はボスと違い、プレイヤーを押し戻さず、無敵の間は通り抜けられる。

#### Scenario: 横から接触して被弾
- **GIVEN** プレイヤーのHPが 5 で、無敵時間が 0 である
- **WHEN** ザコ敵の側面に接触する(被弾判定どうしが重なる)
- **THEN** HPが 4 になり、プレイヤーは小さく上方向へ跳ね上がり、無敵時間が 2 秒になる

#### Scenario: 無敵中は被弾しない
- **GIVEN** プレイヤーが被弾後の無敵時間の最中である
- **WHEN** ザコ敵と重なったまま更新が繰り返される
- **THEN** HPは追加では減らず、プレイヤーは押し戻されずに敵を通り抜けられる

#### Scenario: 無敵が終わると再び被弾する
- **GIVEN** 無敵時間が 0 になり、プレイヤーの被弾判定がザコ敵の被弾判定と重なっている
- **WHEN** 更新が実行される
- **THEN** HPが 1 減り、再び無敵時間が設定される

#### Scenario: HPが 0 になる
- **GIVEN** プレイヤーのHPが 1 で、無敵時間が 0 である
- **WHEN** ザコ敵に接触する
- **THEN** HPが 0 になり、プレイヤーは死亡した状態になる
