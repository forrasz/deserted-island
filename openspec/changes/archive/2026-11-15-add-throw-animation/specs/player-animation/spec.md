# Spec Delta

## ADDED Requirements

### Requirement: ヤシの実を投げる動き
システムは、プレイヤーがヤシの実を投げたとき、そのときの動き(待機・歩く・走る・ジャンプなど)のコマの上に、投げる動きを重ねて表示しなければならない(SHALL)。投げる動きは、既存のコマを加工して作る(新しい絵は使わない): 投げた瞬間から 0.3 秒の間、足元を軸に、進む向きへ体を前に傾け(最大 14 度。投げた直後の 0.08 秒で最大に達し、そのあとなめらかに戻る)、少し横に広げて低くし(横 1.05 倍・縦 0.97 倍)、投げた方向へ振った腕を示す弧(白い半透明の線。0.15 秒で消える)を出す。やられ・被弾・石の硬直の動きの間は、投げる動きを重ねない。ゲームの状態は、投げた瞬間からの経過時間(投げていなければ十分大きな値)を持ち、投げた更新で 0 になり、更新のたびに進む。体を傾ける向きは、プレイヤーの向き(左向きなら反対)に従う。当たり判定・投げる位置・飛び方は変えない。

#### Scenario: 投げた更新で経過時間が 0 になる
- **GIVEN** 手持ちが 1 個以上で、投げていない
- **WHEN** 投げる入力を押す
- **THEN** 投げた更新で、投げてからの経過時間が 0 になり、更新のたびに増える

#### Scenario: 傾きの時間割
- **GIVEN** 投げる動きの時刻表がある
- **WHEN** 投げてから 0 秒・0.08 秒・0.3 秒・0.4 秒の傾きを調べる
- **THEN** 0 秒は 0 度、0.08 秒は最大(14 度)、0.3 秒は 0 度、0.4 秒は投げていない(動きなし)である

#### Scenario: 左向きは反対に傾く
- **GIVEN** プレイヤーが左を向いている
- **WHEN** 投げる動きを描画する
- **THEN** 体は左(進む向き)へ傾き、足元の位置は変わらない

#### Scenario: 投げた弧
- **GIVEN** 投げてから 0.05 秒が経った
- **WHEN** 弧の濃さを調べる
- **THEN** 0 より大きく 1 以下で、0.15 秒を過ぎると 0 になる

#### Scenario: やられなどの動きには重ねない
- **GIVEN** プレイヤーがやられ・被弾・石の硬直の動きである
- **WHEN** 投げた直後を描画する
- **THEN** 投げる動き(傾き・弧)は重ならない

#### Scenario: 投げる位置と飛び方は変わらない
- **GIVEN** 投げる動きがある
- **WHEN** ヤシの実を投げる
- **THEN** ヤシの実の出る位置・速さ・手持ちの数の変化は、動きがなかったときと同じである

### Requirement: ヤシの実を持っているときの表示
システムは、手持ちのヤシの実が 1 個以上あるとき、プレイヤーの手元(進む向きの前側の、胸の高さ)に、ヤシの実を 1 個描かなければならない(SHALL)。手持ちが 0 個になったら描かない。やられ・被弾の動きの間は描かない。ヤシの実の大きさは、プレイヤーの表示の倍率に合わせる。

#### Scenario: 持っているとき
- **GIVEN** 手持ちのヤシの実が 1 個以上ある
- **WHEN** プレイヤーを描画する
- **THEN** 前側の手元にヤシの実が描かれる

#### Scenario: 持っていないとき
- **GIVEN** 手持ちが 0 個である
- **WHEN** プレイヤーを描画する
- **THEN** 手元にヤシの実は描かれない

#### Scenario: 向きに従う
- **GIVEN** プレイヤーが左を向いて、ヤシの実を持っている
- **WHEN** プレイヤーを描画する
- **THEN** ヤシの実は左側(前側)の手元に描かれる

#### Scenario: シートが使えないとき
- **GIVEN** スプライトシートが使えない
- **WHEN** プレイヤーを描画する
- **THEN** 従来の見た目で描かれ、投げる動きと手元のヤシの実は描かれない(ゲームは通常どおり遊べる)
