# Spec Delta

## MODIFIED Requirements

### Requirement: 側面・下からの接触
システムは、プレイヤーが上から踏みつける条件を満たさずに生存中のボスと重なったとき、ボスから離れる水平方向へ押し戻さなければならない(SHALL)。ボスの体力は変化しない。プレイヤーが受けるダメージは、`player-health` の要件に従う。

#### Scenario: 横から接触
- **GIVEN** プレイヤーが地面を歩いてボスの右側から接触する
- **WHEN** 更新が実行される
- **THEN** プレイヤーはボスから離れる方向(右)へ押し戻され、ボスの体力は変化せず、プレイヤーはボスをすり抜けない

#### Scenario: 押し戻しでワールド範囲を出ない
- **GIVEN** プレイヤーがワールドの端に近い位置でボスに接触している
- **WHEN** 押し戻しが適用される
- **THEN** プレイヤーの位置はワールドの範囲内に収まる

#### Scenario: プレイヤーが無敵でも押し戻される
- **GIVEN** プレイヤーが被弾後の無敵時間の最中で、ボスの側面に接触している
- **WHEN** 更新が実行される
- **THEN** プレイヤーは押し戻され、ボスをすり抜けない(ダメージは追加では発生しない)
