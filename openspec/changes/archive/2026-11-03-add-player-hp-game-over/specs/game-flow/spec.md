# Spec Delta

## ADDED Requirements

### Requirement: HPが0になるとゲームオーバー画面へ遷移する
システムは、プレイ中にプレイヤーのHPが 0 になったとき、プレイを終了してゲームオーバー画面を表示しなければならない(SHALL)。ゲームオーバー画面では、ゲームオーバーになったことと、Enter キーでもう一度遊べることを表示する。

#### Scenario: HPが0になる
- **GIVEN** プレイ中で、プレイヤーのHPが 1 である
- **WHEN** ボスに接触してHPが 0 になる
- **THEN** ゲームオーバー画面が表示される

#### Scenario: ゲームオーバー画面の表示内容
- **GIVEN** ゲームオーバー画面が表示されている
- **WHEN** 画面を描画する
- **THEN** ゲームオーバーになったことと、Enter キーでもう一度遊べることが表示される

#### Scenario: ゲームオーバー画面での入力
- **GIVEN** ゲームオーバー画面が表示されている
- **WHEN** 移動キーやスペースキーを押す
- **THEN** ゲームの状態は変化せず、プレイは再開されない

#### Scenario: HPが残っている間
- **GIVEN** プレイ中で、プレイヤーのHPが 2 である
- **WHEN** ボスに接触してHPが 1 になる
- **THEN** プレイは続行され、ゲームオーバー画面にはならない

## MODIFIED Requirements

### Requirement: 再プレイで初期状態に戻す
システムは、クリア画面またはゲームオーバー画面で Enter キーが押されたとき、ゲームの状態をすべて初期状態に戻してプレイを再開しなければならない(SHALL)。前回のプレイの結果は引き継がない。

#### Scenario: 再プレイの開始
- **GIVEN** クリア画面が表示されている
- **WHEN** Enter キーを押す
- **THEN** プレイが開始され、プレイヤーは開始位置にいて、所持数は 0、イカダは未完成、ボスは体力 3 で存在し、ドロップ済みの部品は残っていない

#### Scenario: ゲームオーバーからの再プレイ
- **GIVEN** ゲームオーバー画面が表示されている
- **WHEN** Enter キーを押す
- **THEN** プレイが開始され、プレイヤーは開始位置にいて、HPは 3、無敵時間は 0、所持数は 0、イカダは未完成、ボスは体力 3 で存在し、ドロップ済みの部品は残っていない

#### Scenario: 何度でも繰り返せる
- **GIVEN** 1 回目のプレイをクリアまたはゲームオーバーで終えて再プレイを開始した
- **WHEN** 再び脱出に成功する、またはHPが 0 になる
- **THEN** 再度クリア画面またはゲームオーバー画面が表示され、さらに再プレイもできる

### Requirement: プレイ中のみゲームを進行させる
システムは、プレイ中の間だけ、プレイヤー・ボス・部品の更新を行わなければならない(SHALL)。タイトル画面・クリア画面・ゲームオーバー画面の間は、ゲームの世界を進行させない。

#### Scenario: クリア画面でのボスの移動
- **GIVEN** クリア画面が表示されている
- **WHEN** 複数回の更新が実行される
- **THEN** ボスやプレイヤーの位置は変化しない

#### Scenario: ゲームオーバー画面でのボスの移動
- **GIVEN** ゲームオーバー画面が表示されている
- **WHEN** 複数回の更新が実行される
- **THEN** ボスやプレイヤーの位置、HP、無敵時間は変化しない

#### Scenario: プレイ中の進行
- **GIVEN** プレイ中である
- **WHEN** 複数回の更新が実行される
- **THEN** ボスは往復し、プレイヤーは入力に応じて動く
