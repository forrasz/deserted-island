# Spec Delta

## ADDED Requirements

### Requirement: プレイヤーの被弾判定は見た目より小さい
システムは、プレイヤーが被弾する判定(ザコ敵・弾・衝撃波との重なり)に、見た目(幅 40・高さ 56)より小さい矩形(幅 28・高さ 46)を使わなければならない(SHALL)。被弾判定の矩形は、プレイヤーの下辺と左右の中心をそろえる(左右に 6 px ずつ、上に 10 px 小さい)。踏みつけの判定と、地形との衝突、部品の拾得には、見た目の矩形を使い、変えない。

#### Scenario: 被弾判定の大きさと位置
- **GIVEN** プレイヤーが x = 100、y = 200 にいる(見た目の矩形が 100〜140、200〜256)
- **WHEN** 被弾判定の矩形を調べる
- **THEN** 矩形は x = 106〜134、y = 210〜256(幅 28・高さ 46)である

#### Scenario: 見た目だけが掠る
- **GIVEN** プレイヤーの見た目の矩形が、ザコ敵の見た目の矩形と 5 px だけ重なっているが、被弾判定どうしは重なっていない
- **WHEN** 更新が実行される
- **THEN** 被弾しない

#### Scenario: 踏みつけは、見た目の矩形のまま
- **GIVEN** プレイヤーがザコ敵の真上から落下していて、見た目の下辺が、ザコ敵の上辺に重なる
- **WHEN** 更新が実行される
- **THEN** 踏みつけが成立し、ザコ敵が倒れる

#### Scenario: 部品の拾得は、見た目の矩形のまま
- **GIVEN** 部品が、プレイヤーの見た目の矩形の端にだけ重なる
- **WHEN** 更新が実行される
- **THEN** 部品を拾得する
