# Spec Delta

## MODIFIED Requirements

### Requirement: 左右移動
システムは、プレイヤーが地面・崖・浮島の上に立っている間、左矢印キーまたは A キーで左へ、右矢印キーまたは D キーで右へプレイヤーを移動させなければならない(SHALL)。キーを離したときは水平方向に停止する。空中にいる間の水平の動きは、「ジャンプと重力」に従い、キーでは変わらない。

#### Scenario: 右へ移動
- **GIVEN** プレイヤーが地面の上に立っている
- **WHEN** 右矢印キーまたは D キーを押し続ける
- **THEN** プレイヤーの x 座標は更新ごとに増加し続ける

#### Scenario: 左へ移動
- **GIVEN** プレイヤーが地面の上に立っている
- **WHEN** 左矢印キーまたは A キーを押し続ける
- **THEN** プレイヤーの x 座標は更新ごとに減少し続ける

#### Scenario: キーを離す
- **GIVEN** プレイヤーが地面の上で右へ移動している
- **WHEN** すべての移動キーが離される
- **THEN** プレイヤーの x 座標は変化しなくなる

#### Scenario: 左右同時押し
- **GIVEN** プレイヤーが地面の上に立っている
- **WHEN** 左右の移動キーが同時に押されている
- **THEN** プレイヤーの x 座標は変化しない

### Requirement: ジャンプと重力
システムは、地面に接している間にスペースキーが押されたとき、プレイヤーを上方向へ跳ね上げなければならない(SHALL)。空中では重力により下向きの速度が増え、プレイヤーは放物線を描いて落下する。空中の水平の速さは、地面を離れた瞬間の速さ(その更新の左右キーによる、左 -1・止まる 0・右 +1 に、移動の速さをかけたもの)のまま保たれ、空中で左右キーを押しても離しても、変わらない。

#### Scenario: 地面でジャンプ
- **GIVEN** プレイヤーが地面に接している
- **WHEN** スペースキーを押す
- **THEN** プレイヤーは地面から離れて上昇し、頂点に達した後に下降する

#### Scenario: 空中での二重ジャンプ禁止
- **GIVEN** プレイヤーが空中にいる
- **WHEN** スペースキーを押す
- **THEN** ジャンプは発生せず、上向きの速度は与えられない

#### Scenario: 空中での水平移動
- **GIVEN** プレイヤーが右移動キーを押しながらジャンプして、空中にいる
- **WHEN** 空中で右移動キーを押し続ける
- **THEN** プレイヤーは、踏み切りのときと同じ速さで右へ移動し続ける(空中で押し続けても、速さは変わらない)

#### Scenario: 空中で向きを変えられない
- **GIVEN** プレイヤーが右移動キーを押しながらジャンプして、空中にいる
- **WHEN** 空中で右移動キーを離し、左移動キーを押す
- **THEN** プレイヤーは右へ同じ速さで進み続け、向きは変わらず、止まりもしない

#### Scenario: 止まった状態でジャンプ
- **GIVEN** プレイヤーが地面の上で、移動キーを押さずに立っている
- **WHEN** スペースキーを押してジャンプし、空中で右移動キーを押し続ける
- **THEN** プレイヤーは真上に跳んで真下に着地し、x 座標は変化しない

#### Scenario: 足場から歩いて落ちる
- **GIVEN** プレイヤーが右移動キーを押しながら、足場の端から歩いて出る
- **WHEN** 空中で移動キーをすべて離す
- **THEN** プレイヤーは歩いていた速さのまま右へ進みながら落ち、着地するまで変わらない

## ADDED Requirements

### Requirement: 空中で壁にぶつかると水平の動きが止まる
システムは、空中のプレイヤーが、崖の側面やワールドの端にぶつかって、水平に進めなくなったとき、水平の速さを 0 にしなければならない(SHALL)。そのあとは、壁に沿って真下へ落ちる。

#### Scenario: 崖に空中でぶつかる
- **GIVEN** プレイヤーが右へ跳んで、空中で崖の側面にぶつかった
- **WHEN** 更新が続く
- **THEN** プレイヤーは崖の側面に沿って落ち、崖の中へ入らず、右へ進み続けようとしない

#### Scenario: 壁にぶつかったあとの着地
- **GIVEN** 空中で崖の側面にぶつかって、水平の速さが 0 になった
- **WHEN** 着地する
- **THEN** 着地した次の更新からは、移動キーに従って動ける
