# Spec Delta

## MODIFIED Requirements

### Requirement: 弾と衝撃波による被弾
システムは、プレイヤーの被弾判定が弾または衝撃波と重なったとき、無敵でなければプレイヤーのHPを 1 減らし、小さく上方向へ跳ね上げ、2 秒の無敵時間を設定し、その弾を消さなければならない(SHALL)。無敵の間は被弾せず、弾はプレイヤーを通り抜けて進み続ける。プレイヤーは弾を壊せず、踏んでも倒せない。

#### Scenario: 弾に当たる
- **GIVEN** プレイヤーのHPが 5 で、無敵時間が 0 である
- **WHEN** 直進弾がプレイヤーの被弾判定と重なる
- **THEN** HPが 4 になり、プレイヤーは小さく跳ね上がり、無敵時間が 2 秒になり、弾は消える

#### Scenario: 無敵中は被弾しない
- **GIVEN** プレイヤーが被弾後の無敵時間の最中である
- **WHEN** 弾がプレイヤーと重なる
- **THEN** HPは減らず、弾は消えずに進み続ける

#### Scenario: ジャンプで衝撃波をよける
- **GIVEN** 地面を走る衝撃波が、プレイヤーの足元へ近づいている
- **WHEN** プレイヤーが、衝撃波の高さより高くジャンプして通過を待つ
- **THEN** プレイヤーは被弾しない

#### Scenario: 踏んでも倒せない
- **GIVEN** 直進弾がある
- **WHEN** プレイヤーが落下しながら上から弾に重なる
- **THEN** 弾は倒されず、通常の接触として被弾する(無敵でなければ)

#### Scenario: 死亡する
- **GIVEN** プレイヤーのHPが 1 で、無敵時間が 0 である
- **WHEN** 弾に当たる
- **THEN** HPが 0 になり、死亡した状態になる
