# Proposal

## Why

遊び心の隠しコマンドとして、有名なコマンド「上上下下左右左右BA」を入力すると無敵モードになるようにする。難しいボスやボーナスステージを、ダメージを気にせず試したいときに使える。

## What Changes

- **隠しコマンド**: キーボードで `↑ ↑ ↓ ↓ ← → ← → B A` を順に押すと、無敵モードがオンになる。タイトル画面とプレイ中に受け付ける。スマホ(タッチ操作)は対象外
  - 途中で違うキーを押したら、最初からやり直し(`↑` から数え直す)。キーの押しっぱなし(リピート)は、1 回として数える
  - `A` は左移動のキーでもあるので、コマンドの最後の `A` を押すと、左へ少し動く(許容する)
- **無敵モードの効果**:
  - ザコ敵・ボス・ボスの弾と衝撃波・ボーナスステージの石に触れても、ダメージを受けない(HPが減らず、硬直もしない)。無敵時間の点滅もしない
  - ボスやザコ敵を踏んで倒すことは、これまでどおりできる。ボスの体は通り抜けられず、押し戻される
  - 穴に落ちたときは、直前の安全な足場へ戻されるが、HPは減らない
  - ハートでHPを回復することは、これまでどおりできる
- **やり直しで解除**: コマンドを入力するとオンになり、もう一度入力してもオフにならない。ゲームオーバー・クリア画面からやり直す(決定を押して新しいプレイを始める)と、オフに戻る。ただし、タイトル画面で入力した場合は、そのあとのスタートで始まるプレイにも、オンのまま引き継ぐ
- **表示**: 無敵モードの間は、画面に「無敵モード」と表示し、プレイヤーを金色で描く。タイトル画面でオンにしたときも、「無敵モード」と表示する
- コマンドの判定(順番の判定、リセット)と、無敵の効果は `src/core` の純粋な TypeScript とし、Vitest でテストする。キーの押下イベントの取得は `src/platform/keyboard.ts`、表示は `src/platform/renderer.ts` に置く
- **含めないもの**:
  - スマホのタッチ操作でのコマンド入力、設定画面でのオン・オフ、効果音・演出
  - 無敵以外のチート(HP全回復、ステージ選択など)、コマンドの変更・複数のコマンド
  - 無敵モードでクリアしたことの区別(記録・スコアの区別はない)

## Capabilities

### New Capabilities
- `invincible-mode`: 隠しコマンドの入力判定、無敵モードの効果(被弾・硬直・穴の落下のHP減少の無効)、解除(やり直し)、表示

### Modified Capabilities
<!-- なし: 既存の要件の振る舞いは変えない(無敵モードがオフのときは、すべて従来どおり) -->

## Impact

- 新規コード: `src/core/cheat.ts`(コマンドの進み具合の判定)とそのテスト
- 変更するコード:
  - `src/core/game.ts`: `GameState` に `invincible` を追加。被弾・穴の落下のHP減少・ボーナスの石を、無敵のときは無効にする
  - `src/core/bonus.ts`: 石の効果を、無敵のときは無効にする
  - `src/core/flow.ts`: コマンドの進み具合を持ち、タイトルとプレイ中のキー入力でオンにする。やり直しでオフに戻す
  - `src/platform/keyboard.ts`: キーを押した瞬間のイベント(リピートを除く)を、順に取り出せるようにする。`↑` `↓` の既定動作(スクロール)も抑止する
  - `src/main.ts`: 押したキーを `stepFlow` へ渡す
  - `src/platform/renderer.ts`: 「無敵モード」の表示と、プレイヤーの金色
  - `README.md`(コマンドの追記)
- 既存テストへの影響: `GameState` と `Flow` の型に項目を足す。既定値(オフ)で、既存の動きは変わらない。`stepFlow` の追加の引数は省略可能にする
- 新規依存関係: なし
